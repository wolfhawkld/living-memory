# 计算图

> 计算图用节点和连接表示计算操作及其依赖。

## 核心想法

有向无环的计算图可以安排前向计算顺序，并沿依赖关系传播导数。并非所有知识关系都必须无环。

## 关系网络

- 相关：[[矩阵]] — 对照这个概念理解定义和条件。
- 相关：[[反向传播]] — 沿关系继续探索。

### 合成示例

用合成数值展示一条前向依赖链：`x = 2` 与 `y = 3` 先相乘得到 `6`，再与 `z = 1` 相加，得到 `f = x × y + z = 7`。
