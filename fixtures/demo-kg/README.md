# 示例知识库

这 16 个简短概念用于演示程序行为，使用 progressive-kg 的 Markdown 结构，不来自任何个人知识库。关系标签表示演示性的相关关系。

没有预设学习日期或记忆状态。所有节点初始为未知，只有用户确认重温或补记估计日期后才开始计时。演示环境的操作也会保存在本机数据目录；切换到真实知识源时记录隔离。

这些片段用于软件开发和交互测试，不替代课程、教材或经过核验的个人笔记。

## 图片与 Mermaid 示例

默认示例中的 [Model/计算图.md](Model/计算图.md)包含一张[原创静态 SVG](Model/assets/computational-graph.svg)和一个 Mermaid 流程图，均展示合成例子 `f = x * y + z`（`x = 2`、`y = 3`、`z = 1`，结果为 `7`）。媒体不会增加概念、关系或预设重温日期。

在使用此示例知识源的账号中，点击“刷新知识源”，搜索“计算图”，选中节点后在“知识资料”点击“打开大窗阅读”，查看完整资料中的媒体示例：

1. 静态图片应展示输入、乘法、加法和结果；点击图片可切换原始尺寸。
2. Mermaid 应展示相同计算依赖；用图表旁的“显示原代码”查看定义，再用“显示图形”返回图表。
3. 可切换深浅主题检查图表、文字及容器；静态 SVG 保留自身配色，不随主题反色。

若你的账号使用自有知识库，此示例不会自动加入其中；可在独立示例环境中测试，或把该笔记连同 `Model/assets/` 附件目录复制到自己的测试知识目录。成员初始知识库为空，也需自行放入这份合成示例。详细图片路径规则与图表操作见[阅读说明](../../docs/development/markdown-reader.md)。

自动解析和附件检查与人工视觉验收分别记录。此处提供可复现材料，图片/Mermaid 的实际缩放、主题、滚动与焦点体验仍由使用者验收。
