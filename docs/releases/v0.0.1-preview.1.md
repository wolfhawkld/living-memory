# Living Memory 0.0.1-preview.1

发布日期：2026-10-01。首个桌面优先的本地 Web 预览版已发布为 prerelease，MIT 许可，分发源码。固定 tag 为 `v0.0.1-preview.1`，目标提交 `1c7a639c8f5517cbb9435ed459efdf739066e4c1`；CI、源码归档核对和实际时间见[发布记录](preview-publication-2026-10-01.md)及 [GitHub 预览发布](https://github.com/wolfhawkld/living-memory/releases/tag/v0.0.1-preview.1)。源码 tag 保留发布前准备文档，本页在后续分支更新实际结果。

## 运行固定版本

以下命令使用固定 tag；参与开发使用 `develop`，见[贡献指南](../../CONTRIBUTING.md)。推荐 Node 22.23.1（见[版本文件](../../.nvmrc)），已验证 npm 10.9.8：

```bash
git clone --branch v0.0.1-preview.1 --single-branch https://github.com/wolfhawkld/living-memory.git
cd living-memory
npm ci
npm run build
npm start
```

打开 `http://127.0.0.1:4317`，自行创建第一个管理员，**没有默认密码**。默认 16 个合成概念、32 条关系，无需安装 progressive-kg。初次示例时间是虚构的；切换真实记录后，未确认重温的节点保持未知。自有知识、账号和数据位置见[新人指南](../development/first-run.md)。

GitHub 自动提供 tag 的 ZIP/TAR 源码归档，也可解压后执行同样的安装命令。源码包不包含 `node_modules`、`dist`、私人数据库或知识库；首版不提供安装器、npm 包或在线服务。第三方依赖与未来构建包的许可范围见[许可检查](third-party-licenses.md)。

## 包含的功能

- Markdown 知识的 3D/2D 图谱、深浅主题、全库搜索、领域/跨域浏览、镜头适配、发光与空闲旋转。
- Markdown 大窗、公式、图片与 Mermaid；Web 和 CLI 查询完整概念索引。
- 本人明确重温、估计日期补记、学习历史、概念/场景回忆、信心与核对证据、本人固定长期保持。
- 少量复习、重点/暂缓、预算和续做；应用/总结、修正建议与学习对照总览。
- 本机管理员/成员隔离、JSON 导出/预览恢复、人工确认概念身份衔接、待同步协调与幂等重试；可选 KG 成功收尾刷新钩子。

## 记忆与数据边界

模型是 `time-only-v0`，`D(t) = 2^(-t/H)` 仅提供时间提示，H 默认 7 天；它不是测出的记忆正确率或个人遗忘参数。查询、阅读、生成和刷新不会自动确认重温，观察/信心/应用暂不拟合 H，固定长期保持仅本人手动解除。

学习 JSON 为 `schemaVersion: 1`，不是整机备份。升级前先同步待写入、停止服务，完整保留数据目录、外部知识和目录外 CLI 状态；原路径恢复和 JSON 的区别见[备份/恢复](upgrade-and-recovery.md)与[兼容约定](versioning-and-compatibility.md)。当前 SQLite 没有通用迁移框架，也不承诺稳定公开 API 或任意新旧客户端混用。

已有 WSL2/Linux x86_64 的干净安装、HTTP/CLI、两账号合成恢复、38 项兼容专项与构建证据，详见[恢复验证](upgrade-validation-2026-10-01.md)。最终发行提交的 [main CI](https://github.com/wolfhawkld/living-memory/actions/runs/36852873767) 全部通过，含 496 项 Node/HTTP、构建、主题及 10 项 Chromium 回归；本地与 GitHub 的源码归档逐文件核对一致，详见[发布记录](preview-publication-2026-10-01.md)。软件渲染回归不代替真实 GPU 验证。
