# README 示意素材

`readme-demo.svg` 是原生静态 SVG 示意图，`readme-demo.json` 是对应的数据文件。图像宽 1100、高 520，采用 `DARK_THEME` 的暗色配色，左侧展示 Math 子图，右侧展示时间状态图例。它不是应用截图，不代表实际镜头、动画或 GPU 性能。

从仓库根目录重新生成两个素材：

```sh
npm run generate:readme-demo
```

生成脚本显式读取 `fixtures/demo-kg`，通过 `loadKnowledgeGraph` 解析 `Math` 目录中这六个公开演示概念：向量、矩阵、范数、内积、余弦相似度、正交。图中的关系来自解析器实际解析出的关系；JSON 保留 11 条关系的方向、类型和相对来源路径，图中有 8 个节点对，反向关系可能重叠。箭头表示笔记中的关系方向，不表示因果。布局坐标固定，便于 README 中稳定引用。

时间状态使用固定的 `asOf=2026-10-01T00:00:00.000Z`、半衰期 `H=7` 天，以及按概念顺序分配的虚构重温间隔 `0、3、7、14、null、21` 天。脚本为有间隔的概念构造合成锚点，并调用 `projectMemory` 取得状态和衰减值；`null` 保持为 `unknown`。这些值只说明时间模型如何投影示意数据，不代表记忆、学习表现或回忆概率。

素材用途是介绍项目的 README 和公开文档。JSON 明确标记 `synthetic=true`、`notForLearningImport=true`，不包含用户数据、持久化学习历史、账号、数据库、命名空间或根目录绝对路径；它不是学习导入格式，也不应被当作个人记忆记录。SVG 内嵌文字、图形和轻微节点发光滤镜，没有浏览器截图、外链字体、外部图像或脚本。
