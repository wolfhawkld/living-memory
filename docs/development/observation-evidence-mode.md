# 回忆记录的作答方式与本轮回归

日期：2026-10-07。对应 FEISHU-03A 的数据与展示前置部分。按用户要求，本轮优先回归新增内容，不继续实现飞书复习会话或学习写回；既有[知识卡片与待复习查看](feishu-card-browsing.md)仍是只读、默认关闭，真实飞书客户端待验。

## 明确脑中回忆与书面记录

回忆观察新增可选 `evidenceMode`，与自评 `rating`、提示条件和资料曝光分别保存：

| 值 | 含义与校验 |
| --- | --- |
| `mental` | 本人脑中回忆，没有保存原答；`answer` 必须显式为 `''`，不填系统生成的假回答 |
| `written` | 本人明确标为书面作答；允许真实留白，不从答案长度推断成绩 |
| 缺失 | 作答方式未记录；旧记录保持缺失，不因空答案自动变成脑中回忆 |

API 与 Store 均验证该字段。非法值或脑中模式携带非空 / 非字符串答案返回 `INVALID_EVIDENCE_MODE`；同一事件改模式返回 `EVENT_CONFLICT`。重试必须保留原事件 ID、模式、答案和其他冻结字段。

历史显示「脑中回忆，未记录原答」，不为它提供展开原答按钮，也不显示成空白书面回答。进展、总览和时间对照的 metadata 保留模式，脑中结果明确标为自报。

这部分只提供数据与展示基础；Web 普通回忆继续使用已有请求格式。本次前置回归当时没有飞书自评入口，后续单条写回实现见[飞书单条复习](feishu-single-review.md)，不把基础字段完成等同完整闭环。

## 证据与记忆边界

- 脑中自报仍保留 `clear / partial / blank` 自评；空 `answer` 不表示一定想不起来。
- 脑中记录不计入独立场景成功或信心校准，即使上传的数据自行声称独立、未曝光或高信心；场景自报仍保留在待核对筛选中。
- 明确看过资料、收到提示或查阅后的脑中记录保留已知协助条件。其他脑中记录归为未知条件，不能因聊天未展示正文就声称未曝光独立回忆。
- 比较明确脑中与书面记录时显示条件不同；只有一方记录方式时显示未知。双方都没有新字段时沿用历史比较规则。
- 保存观察不更新重温起点、不改变全局 H、不解除长期保持。已保存的概念观察仍按现有自然日规则计入每日完成数；场景记录不算概念复习完成。

## 存储与兼容

学习 SQLite 的 `observations` 表增加可空 `evidence_mode` 列；旧行保持 NULL，原请求载荷不改写。缺失字段不添加默认值，以保留旧事件原样重放的去重行为。历史查询、导出、导入预览 / 确认、重启和路径＋版本映射均保留显式模式。

学习 JSON 仍为 `schemaVersion: 1` 的可选字段扩展。使用包含本字段支持的版本恢复带模式的备份；旧版本可能忽略模式，不能保证脑中证据边界。完整备份、升级与回退仍按[现有步骤](../releases/upgrade-and-recovery.md)，兼容范围见[版本说明](../releases/versioning-and-compatibility.md)。
