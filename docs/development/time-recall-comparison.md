# 时间提示与回忆表现对照

更新：2026-09-27。用于 P0-5 / LM-018 的个人观察准备，帮助查看时间提示与自己的回忆自评是否一致。它提供软件观察入口，真实经过时间的试用仍需本人进行。

## 使用入口

1. 在真实学习记录模式打开「知识薄弱点总览」，切换到「时间与回忆对照」。
2. 按领域或概念名称缩小范围。选择「确认重温」或「估计日期」，再选择未报告提示、提示/查阅或条件不明。
3. 查看三个时间阶段中清晰、模糊、想不起的记录数与概念数。可筛选「近期仍模糊」或「较久仍清晰」，点击概念进入节点详情，查看历史或安排下一次练习。

每个概念显示最新一条符合当前条件的记录，并标明匹配记录数；顶部计数包含所选日期依据、提示条件下的全部适用记录。焦点筛选只改变概念列表，不把顶部阶段计数改成另一套样本。列表按观察时间排列，每次最多展开 50 个概念。

还没有可对照的记录时，可以确认或补记真实重温日期，随后在合适的时间先尝试回忆、再核对并保存自评。确认重温与保存回忆观察是两个独立动作；不要为了让图表有数据而虚构过去的学习日期。

## 如何读取这些数字

三个时间阶段沿用时间基线的边界：

| 阶段 | 当次观察距所引用重温起点的时间 | 当次冻结时间指标 |
| --- | --- | --- |
| 近期 | 少于 1H | D > 0.5 |
| 需要再访 | 1H 至不足 2H | 0.25 < D ≤ 0.5 |
| 较久未重温 | 至少 2H | D ≤ 0.25 |

H 是每条观察保存时的参数，不一定等于今天的设置。表中同时展示当次间隔、H 和参数版本，后续调节 H 或再次重温不会改写这些历史数据。不同 H 的记录按各自阶段汇总；不能把阶段相同解释为实际间隔天数相同。

- 「近期仍模糊」匹配近期阶段中的模糊或想不起自评；「较久仍清晰」匹配较久阶段中的清晰自评。这些是值得进一步查看的现象，不诊断原因。
- 默认使用确认重温、未报告提示的记录。估计日期单独查看，不能与确定日期视为同样精确。
- 曾查看资料、报告提示或查阅的记录进入提示/查阅组；提示或曝光条件缺失的旧记录进入条件不明组，不自动推断为无提示。
- 未报告提示不证明没有近期接触；概念名本身是当前回忆任务的允许线索。一天内重复作答仍是多条练习记录，不能冒充多个独立延迟实验。
- 清晰/模糊/想不起是本人自评。记录数和概念数分开展示，时间指标不是回忆概率；本功能不计算“预测误差率”、拟合遗忘曲线或宣称记忆改善。

场景调用的线索和评价目标不同，因此不混入这张概念解释对照；仍可在原总览中查看。手动长期保持也不会被该视图自动解除。

## 数据边界

仅使用当前私人知识空间、当前概念资料版本中已经同步的回忆观察。旧资料版本保留历史与既往计数，不套用为新资料的表现。离线待同步、示例状态和时间滑块模拟不进入统计。

计算引用每条观察的原始锚点，核对概念、资料版本、时间和冻结指标；没有重温起点的记录、缺失指标和不一致记录分别计数提示。锚点校验不重新选择今天最新的重温起点，也不覆盖原始观察。

每个概念最多返回 18 组汇总（3 个阶段 × 2 类日期依据 × 3 类提示条件），每组仅携带计数和至多三条最新记录的元数据。接口不返回回答、业务场景、知识正文或应用内容；查看对照不会产生资料曝光、重温或其他学习事件。仍沿用总览的账号隔离、请求取消、来源核对和跳转前版本复核。

旧服务缺少对照数据字段时，页面提示更新本地服务，不把它描述为没有练习记录。刷新失败时保留已有数据并标注错误，节点跳转暂不可用。

## 验证范围

442 项 Node 测试、TypeScript/Vite 构建及主题构建检查通过。本地服务已备份后更新，原学习事件、参数历史、复习安排和布局逐条比对保持不变；没有数据库格式迁移。

自动检查使用合成知识源和临时学习库，覆盖冻结历史值、H 边界、估计日期、提示条件、缺失数据、来源版本变化、隐私字段过滤、不同账号、只读不变性和静态界面输出。实际浏览器效果由用户验证；没有运行浏览器或 Playwright。

建议试用时选少量真正关心的概念，记录当时的接触条件，再经过真实时间完成一次后续回忆。软件测试不能代替这一步，也不代表完整 LM-018 或记忆收益验收通过。
