# 原答清除：集中验收

本清单针对显式 v3 软件。默认 v2 私人服务不会自动升级，也不会显示清除按钮。先在隔离实例使用测试回答；私人升级按[实例迁移](instance-migration.md)另行安排。自动化软件证据见[统一交付 goal](../planning/answer-clearing-delivery-goal.md)。

## 一次集中检查

1. 在真实记录模式保存一条带文字的回忆观察，进入该概念的「学习历史」。点击「清除这条原答」，核对说明后先取消：原答应仍可展开。
2. 再次打开并确认。应显示服务端原答已清除及本地清理结果；历史显示首次清除时间。原自评、场景、独立应用／总结和修订说明保留，重温时间与长期保持不变。
3. 同时打开第二个标签页，展开原答或打开修订窗口并输入说明。在第一个标签页清除后，第二页应撤下原答，保留独立修订说明；刷新或重新打开也不能恢复原文。
4. 如果遇到网络中断，查看「原答清除待处理」，点击「核对服务端状态」。未确认前应暂时隐藏原文；不会自动重复发清除请求。核对仍保存时，可以明确重试同一记录。
5. 若显示本地副本未完成清理，恢复浏览器存储后点「重试本地清理」。这只重试当前浏览器的副本处理，不会新增复习或更改首次清除时间。
6. 深色、浅色各看一次确认窗口：标题、说明、操作状态和按钮应可读，键盘可聚焦，取消或关闭后返回原位置。

以上应使用可丢弃的测试回答。无需为了验收删除重要私人内容，也无需改动飞书记录。飞书日／周计数与导出恢复边界由隔离自动化集成覆盖；真人使用收益与软件正确性分别观察。

## 范围说明

本功能清除当前保存记录的原答，以及当前软件能定位的同一事件机械副本。其它离线设备、旧版页面、下载过的备份、数据库 WAL／释放页及外部副本不属于已擦除对象。原答和独立场景／总结可能表达相似内容，本功能按字段与事件识别，不按文字相同批量删除。
