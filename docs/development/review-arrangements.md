# 复习安排与中断续做

更新：2026-09-27。LM-012 的安排扩展，继续使用时间候选，不改变 H、重温起点、长期保持或练习评分。

## 操作入口

- 在真实记录、实时时间下，左侧「少量复习」点击「复习安排」，设置每日预算。默认 5 个，可设 1–50 个，跨所有知识域共用；单轮仍最多 3 或 5 个。
- 选中节点，在「节点复习安排」中开启重点，或暂缓 1 天/7 天；可随时取消暂缓。暂缓从操作时间计时，到期自动回到原候选规则，不自动生成重温记录。
- 练习过程中点击「暂停，稍后继续」，或刷新页面后，在左侧继续未完成的一轮。保留队列、位置、作答阶段、回答、原事前信心和已完成进度。
- 「跳过本条」只影响本轮；「结束本轮」或「放弃」删除当前浏览器的断点和未提交草稿，已保存与待同步记录仍保留。未提交作答可以复制出来。

重点只调整已有时间候选的顺序；暂缓优先于重点。长期保持、未知起点、版本不符、近期重温和本地待同步节点不会被重点强行加入队列。默认顺序为重点在前，同组按距重温时间从长到短，再按概念 ID 稳定排序。

## 每日预算的含义

预算按浏览器时区的自然日计算，服务端返回当前日期和已保存的概念回忆 ID。同一节点一天只计一个，包括节点入口的手动回忆与少量复习；旧资料版本的当天回忆也计入当天投入。场景观察、应用/总结、浏览、重点/暂缓设置、跳过及单独确认重温不计入这个概念回忆预算。

今日待同步的概念观察单独显示，并与已保存节点去重后暂占名额。采用观察发生时间；隔日同步不会把昨天完成的回忆算成今天。它们仍是待同步记录，不会被宣称已经保存。已保存与待同步概念当天不重复自动推荐。

预算是轻量安排上限，不是强制服务端配额，也不是掌握分数。用完后不再自动开始新题，可以暂停明天继续，或修改预算；手动回忆一直可用。已经开始的作答可以完成，即使暂停期间预算调低。多个设备或同时进行的练习可能超过预算，系统不删除或拒绝真实观察来凑数。

打开页面、快照变化、日期变化、开始/继续/下一条时会读取安排；每次进入新题都重新核对。窗口跨过午夜后刷新当天统计，开始下一题时仍以服务端当前日期为准。

## 保存、恢复与隔离

每日预算、重点和暂缓存入当前账号对应的 SQLite namespace，随学习数据导出。偏好跟随现有概念 ID：资料内容更新保留本人安排意图，但当前版本必须重新满足记忆起点等候选条件。移动/改名导致 ID 改变时仍需要后续身份衔接功能；移除概念的偏好保留在导出中，不生成幽灵候选。

安排写入使用版本比较，防止旧标签页覆盖新设置；失败时保留界面草稿，读取最新安排后重试。这类设置不放入学习事件待同步队列，也不写入知识 Markdown。

续做断点仅在当前浏览器的 `localStorage`，按私人知识源隔离，不上传到学习库，不包含在服务端导出里。作答会自动保存；提交观察或确认重温前先保存固定请求 ID，使刷新后的重试仍是同一事件。已进入本地待同步队列的观察恢复成进度，不再打开成新题；已确认或待同步的重温会核对原事件 ID。

恢复不会自动展示资料、自动提交或创建新的信心预测。未提交题目恢复前核对概念、内容版本、领域、重温起点、暂缓与长期保持。条件已变化时保留原草稿，提示先复制，再放弃本轮重新安排。已完成题目可以恢复到进度页，进入下一题时继续重验。核对阶段的资料曝光标记继续有效，不把恢复伪装成新的一次未曝光回忆。

浏览器拒绝存储、容量不足或断点损坏会明确提示，不能宣称已经保存。损坏原数据不被新轮次静默覆盖。另一个标签页修改同一断点时，当前页保留作答并停止自动覆盖，提示复制后重新加载；当前首版不提供多标签页同时编辑一份草稿或跨设备续做。

## 接口与检查

`GET /api/review-plan?timeZone=Asia%2FShanghai` 读取当前私人安排和每日数量；`PUT` 同路径写入每日预算，或一个节点的重点/暂缓设置。写入需要会话令牌及当前知识源，概念设置额外核对当前资料版本。响应不含回答或知识正文。只新增独立安排表，兼容现有学习数据。

检查范围：重点与暂缓边界、长期保持不能被绕过、时区/午夜与当天去重、版本冲突、账号隔离、持久化和导出、断点损坏/失败/来源隔离、未完成表单往返、固定事件 ID、恢复前资格重验及待同步衔接。浏览器视觉由用户验证。
