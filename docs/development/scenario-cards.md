# 人工场景卡与分阶段提示

本批承接 LM-011：帮助观察“面对问题能否想到候选概念”与“能否解释候选为何适用”这两个不同缺口。入口是图谱上方的「私人练习卡」，选择场景类型。已有「场景调用练习」仍用于自由记录工作问题和回访旧观察；这里用于本人维护的、可重复练习的场景题。

## 编写少量场景

手工填写题干、核对答案、出处与案例族标签，关联 1～4 个不同概念的当前资料版本；保存前确认已核对来源。结构提示和名称提示均可留空。结构提示可以提醒数据形态、约束或关系；名称提示可以直接给出候选方法。提示内容也由本人核对，系统不自动生成、评分或要求唯一答案。

案例族只是人工分组：使用完全相同的标签归为一组，系统不会自动判断两个问题是否等价或是否真的全新。修订保留题目版本和旧回答；修改案例族不会将旧回答重新归到新族。查看编辑器、旧答案和来源后再练习，应如实保留已有接触条件。

## 先答，再按需提示

1. 开始前可填信心，并报告是否见过这道题或同案例族。系统已经看到该卡或该族有保存的练习时，会保守标为已见；没有历史并不能证明这是新问题。
2. 只看题干写下原答，允许空白。此时不展示参考答案、关联概念、案例族、旧答或尚未请求的提示；图谱与搜索也无法操作。
3. 可直接提交核对，也可提交原答后看结构提示或名称提示。每次请求下一阶段提示前，先固定当前回答与时间。可以跳过结构提示，不能撤回已显示的提示或回填最初原答。
4. 最后看核对依据，逐阶段分别评价「候选召回」与「适用理由」：准确、部分准确、未成功或暂不判断。合理的替代方法需要核对其前提与理由，不能只按是否命中参考名称评价。
5. 说明外部提示 / 查阅及核对笔记，再保存。事前信心只对应最初原答；核对后的判断和提示阶段的答案分别保留。

名称提示后能够解释方法，不能据此认定已经能在无提示场景中想到它。结构提示也可能包含答案线索，实际提示条件必须一起看；题干本身若含概念名，首段也不构成自发召回证据。同卡或同案例族重复练习用于再练，不据此认定新场景迁移。

记录中的 `independent` 阶段仅表示尚未显示系统提示，不保证没有外部线索；实际独立与否还要结合本人报告的查阅、辅助条件和已知曝光。外部辅助发生在哪一段，可以写进核对笔记。

## 历史、失败和来源变化

历史保留题目、案例族、提示版本，以及每阶段的原答、时间和两项自评。当前版本的结果与较早版本分开；暂停 / 恢复也追加卡片版本，原记录不删除。

任一来源变化或删除后，先核对当前资料并追加修订，才能开始新练习。已经成功保存的原请求可重复取得回执；未成功的旧版本请求不会自动换到新版本。保存失败保留同一请求，进入浏览器待同步队列后须等待同步成功，才会出现在服务端历史和导出中。

未保存输入关闭前提醒丢弃；未提交草稿只存在当前页面，刷新不能保证恢复。编辑器、核对和历史的资料曝光按原浏览器会话规则保守保留，外部阅读仍由本人报告。

## 数据边界

继续使用 `/api/practice-cards`、`/api/practice-attempts` 与分卡历史接口，按私人知识空间隔离。`kind: "scenario"` 的卡片有 `scenario: { caseFamily, structureHint, nameHint }`；作答的 `scenario` 保存各阶段回答、显示提示和作答时间、候选召回 / 适用理由自评及案例接触条件。顶层回答和作答时间仍为最初原答，顶层统一结果保留为「暂不判断」，不把两项判断压成一个成绩。

JSON 的可选 `practice` 部分完整包含这些字段，支持预览映射、事务恢复与精确重复回执。旧备份没有场景卡仍可恢复；需要本轮或更新版本才能完整恢复新增场景字段。旧数据库升级保留旧卡、回答、来源引用与幂等载荷；升级前仍按[恢复约定](../releases/upgrade-and-recovery.md)停止服务备份整个数据目录。

新场景卡属于独立练习记录，不写入原 `Observation`，不进入旧场景汇总、概念解释成绩、信心校准、每日概念预算或时间表现对照。所有操作不改 H、重温起点、手动长期保持或 progressive-kg；没有按练习表现自动升级复习间隔。

本批 46 项定向、574 项完整 Node / HTTP 测试通过（新增 21 项），构建与主题产物检查通过。合成检查覆盖阶段冻结 / 时间顺序、旧库迁移 / 回执、跨根恢复、账号隔离与原记忆状态不变性；最终界面文案调整后复查构建与盲答渲染。

本批软件检查完成后，可与[细节 / 辨别卡](practice-cards.md#集中人工验收)和[旧场景回访 / 总结](scenario-revisit.md)一起测试：

1. 建一张来源已核对的场景卡，给两级提示。先写原答，提交后依次请求提示；确认每段原答不被后续编辑覆盖，未请求提示、候选名称与旧答案不提前显示。
2. 分别给候选召回和适用理由不同自评，保存刷新查看逐段历史；再练同题，检查已见标记。可以再建一张同族题，查看案例族接触提示。
3. 修订或暂停 / 恢复，确认旧题旧答和概念原有衰减 / 长期保持仍在；来源变化与恢复流程使用隔离测试知识源，避免为测试修改生产笔记。
4. 在隔离账号 / 数据目录预览恢复 JSON，确认场景提示、各阶段原答、两项自评、来源版本与精确重复回执保留。

自动验证只使用合成资料和隔离存储。浏览器视觉、题目与提示质量、实际延迟回忆及新场景调用效果尚待本人验收；软件功能完成不代表完整 LM-011 或记忆收益已经验证。
