# 查询与阅读过程记录

查阅记录用于回看一次查询提供了哪些候选、选中了哪个概念、打开了哪份资料，以及哪些文本块进入了阅读窗口的可见区域。它不代表读完、理解或记住，不参与半衰时间 H、重温锚点、长期保持、自评或复习预算计算。

## Web 使用

真实记录模式下，搜索框明确点击「查询」或成功选择候选时记录查询步骤；输入草稿不会逐键保存。没有结果的查询也可以提交。默认仅保存候选概念、资料版本与时间；「仅本次保存查询原文」需要主动勾选，每次修改或清空输入后复位。查询前回忆中的原始作答仍属于原任务，不进入查阅记录。

打开阅读大窗会产生打开资料事实；只有当前最上层阅读窗口、页面可见、真实 Markdown 渲染完毕后，与视口相交的已核验文本块才产生可见范围事实。摘要与正文分别定位，章节目录和跨笔记引用沿用同一次阅读操作。列表项、表格按块记录，图片占位、Mermaid 和数学渲染不作内容已阅读的证据。

「查阅记录」提供概念、渠道和时间筛选、分页、独立导出、暂停／恢复、清除此操作和清除全部。清除仅影响当前账号知识空间的查阅记录、查询原文和递送记录，保留学习历史。清除后仍打开的阅读窗口不会自行重建刚删除的轨迹；下一次主动打开资料才开始新的阅读操作。

## 保存与失败处理

活动记录保存在学习 SQLite 连接内的独立 `activity_*` 表，使用当前认证用户与知识空间归属；客户端的 user／agent 字段只是活动声明，认证归因由服务端添加。概念 ID、版本、路径及块范围冻结后保留，不用当前资料静默替换历史引用。客户端路径不用于打开文件。

浏览器使用独立的账号／知识空间／实例队列，最多 100 条、512 KiB。事件、操作步骤、递送 ID 和原发生时间在重试时保持不变；单次同步最多 10 条，每条瞬态错误最多自动尝试 3 次，再由用户明确重试。存储不可用或容量不足会提示未保存，不阻断知识查询或学习操作。示例、未来时间预览、会话失效或追踪设置未知时不采集。

暂停和全部清除会提升服务端 epoch，阻止旧窗口迟到请求恢复记录；单次操作清除留下仅含标识的墓碑。设置修改使用 revision 比较，全部及操作清除使用 epoch 比较；失败不自动重发清除。

## 导出边界

独立 JSON 为 `format: living-memory-activity`、`version: 1`，包含活动和递送事实，不是原有 `schemaVersion: 1` 学习备份。当前不提供活动 JSON 导入，学习导入明确拒绝此格式。[完整离线迁移](instance-migration.md)直接包含数据库；浏览器尚未同步的记录仍需单独处理。迁移会更换实例标识，使旧浏览器队列、复习断点和旧 CLI 收据保持隔离，不自动重放。

## 资料变化后核对

历史引用旁分别显示接收当时的核验结果和今天的定位状态：仍可定位、版本变化、路径移动、概念缺失或章节／块失效。原事件、发生时间、路径、版本和范围保留；当前状态只在查询时计算，不写回历史或独立导出。

「核对当前资料」会重新获取当前完整知识索引，对照原引用与当前候选。即使概念身份相同，也需要明确选择当前全文或当前章节，确认前再次校验版本；追踪开启时另记新的阅读引用，暂停追踪时仍可阅读。相同标题或相同章节 slug 不足以自动把旧内容映射到新内容。

移动或改名仍沿用已有人工历史衔接流程。疑似拆分、合并或删除后重建，保持待人工核对：可以明确选择当前资料阅读，但不自动登记概念身份、不复制旧学习成绩或长期保持状态。本轮不提供拆分合并的持久谱系或自动映射，也不保存旧版全文快照。

## 其他渠道的事实边界

CLI 的查询、展示结果属于已准备输出；progressive-kg 的成功触发属于调用方报告成功且刷新完成。飞书分别保存有效查询／选择请求和平台接受投递、失败或未知结果；正文分页只记录页码与版本，不伪造浏览器的精确可见块。以上均不能证明本人已收到、读完或掌握。渠道追踪失败不阻断原有查询、发送或学习确认。

CLI 使用独立、有容量限制的私有活动收据，可用 `activity-retry` 明确重试，`activity-clear-local --confirm` 清除本地活动收据。Web 清除不会删除另一设备或 CLI 目录里的离线文件；旧 epoch／操作墓碑仍阻止它们恢复服务端已删除的记录。本地清除也不会删除服务端历史，详见 `npm run lm -- --help`。原有重温收据与活动收据分开，查询原文默认不存，CLI 仅在明确传入 `--save-query` 时保留。

## 检查范围

开发使用隔离的临时知识文件、账号和数据库，检查幂等、严格字段、来源版本、权限隔离、清除防恢复及学习导出不变。精确提交及已确认结果见[本轮检查证据](../planning/iteration-todo-2026-09-22.md#本轮自动检查证据)；浏览器视觉与目标设备性能由使用者验证，不用单元测试宣称观察器已经在真实页面验收。
