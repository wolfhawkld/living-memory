# 知识薄弱点总览

更新：2026-09-27。LM-012 的多维证据查看子集，帮助从已有记录中选择下一次值得练习的概念，不增加遗忘模型参数或自动评分。

## 使用入口

在「真实学习记录」且实时时间下，点击领域栏的「知识薄弱点总览」。总览使用大窗，默认展示当前账号的全部知识域，可以切换当前领域、按概念标题/ID 搜索，并按以下条件筛选：

| 筛选 | 含义 |
| --- | --- |
| 全部 | 所有当前概念，包括没有练习记录的概念 |
| 回忆困难 | 当前资料版本的最近一次概念自评为模糊或想不起 |
| 场景待核对 | 最近一次场景观察尚未明确独立成功：部分成功、失败、未核对、依据不明、借助提示/查阅或曝光状态不明等 |
| 信心对照 | 至少有一条符合原有校准条件的概念或场景记录，分别显示信心、核对成功率、差值和样本数 |
| 缺少练习证据 | 当前资料版本没有回忆或场景观察；只有应用/总结也仍属于缺少练习证据 |

“场景待核对”包含辅助成功和条件不明，并不宣称这个概念不能用于工作。“缺少练习证据”也不等同于遗忘。时间状态、本人确认的长期保持、应用/总结计数单独展示，不充当练习成绩。

默认排序先显示最近仍有回忆困难/场景待核对线索的概念，再显示有练习、仅有应用/总结以及无证据的概念；同组按最近记录时间排序。信心对照按两类任务中绝对差值较大的排前，随后参考可比较样本数和最近记录；这只是查看顺序，不是综合能力分数，也没有引入一个“合格”阈值。

列表按 50 条逐批展开。「查看节点」会读取当前索引，再核对概念 ID 与资料版本，切换到相应知识域并选中节点。概念更新或被移除时会要求刷新总览，不会悄悄把旧证据套用到新版本。查看总览和跳转只展示统计元数据，不标记答案曝光、不新增学习事件。

同一窗口还提供「时间与回忆对照」和[知识修正待办](correction-overview.md)独立视图。修正待办按原应用/总结逐条展示，保留旧资料建议及人工决定，与下述当前版本的回忆成绩统计分开。

## 统计边界

- 按概念 ID 和当前 `sourceRevision` 汇总，旧版观察/应用只显示计数，不进入当前成绩或信心比较。已移除概念不在当前总览中，原学习记录仍保留在数据导出内。
- “最近一次”按发生时间、记录时间、事件 ID 确定，补记的旧事件不会覆盖发生时间更新的记录。困难后最近一次自评清晰，或场景独立成功且已核对，对应筛选线索会移除；历史失败次数仍可见。
- 校准沿用现有条件：事前信心、独立作答、未曝光资料、明确成功/失败和已知核对依据。部分成功、未核对、辅助/曝光及旧的无校准信息记录不混入校准。
- 概念解释和场景调用分开显示。信心差值 = 平均事前信心 − 核对成功率；正值表示这批记录里信心更高，负值表示更低。结果由本人核对；尤其样本少时，不据此断言稳定能力或自信倾向。
- 只读取服务端已同步数据，不把浏览器待同步请求当作成功写入。窗口中显示待同步数量，同步成功后可刷新总览。
- 数据在打开与手动刷新时读取，并显示读取时间。窗口打开期间保留当前视图；关闭后沿用原有后台变化刷新机制。

## 接口与验证

`GET /api/learning-overview` 返回 `sourceId`、`asOf` 与概念级统计。使用当前私人账号的完整知识索引，不受单领域图谱显示数量限制，不支持传入别人的 namespace 或任意数据库位置。继承已有账号鉴权、知识空间核对与 `no-store` 响应。

返回字段只含概念 ID、标题、目录域、版本、时间提示及练习统计，不含知识正文、原始回答、场景原文或应用/总结文本。服务端不改数据库结构；查询不改重温起点、长期保持、H 或历史事件。

自动检查覆盖：版本/概念隔离、时间与排序边界、旧失败后的成功、辅助与校准条件、只读不变性、跨账号隔离、全量索引、响应不含正文，以及取消/切换后的迟到请求。2026-09-27 完整 319 项 Node 测试、生产构建及主题构建检查通过。浏览器视觉测试由用户进行。

建议试用：打开全库总览→按领域/条件筛选→检查现有节点的自评和样本数→点击跨领域节点→返回总览刷新。没有练习的概念应显示缺少证据；本人确认长期保持的节点若有练习困难仍可出现，不会被系统自动恢复衰减。
