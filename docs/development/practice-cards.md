# 关键细节与概念辨别练习

**2026-10-02 使用反馈：** 用户认为手工设计与维护成本过高，暂缓将私人练习卡用于日常学习及集中验收。已有功能、记录与恢复保留；后续改为自动生成和维护、本人少量确认，见[方向调整 TODO](../planning/automatic-practice-backlog-2026-10-02.md)。以下仍说明现有实现，暂停不代表功能被删除或自动化已完成。

本批为 LM-010/LM-011/LM-012 的人工练习卡子集。入口是图谱上方、与「知识薄弱点总览」同排的「私人练习卡」（原「细节与辨别练习」），使用当前账号的私人知识空间。可以先创建少量问题，之后从这里主动再访；没有每天必须完成的题量。

## 两种任务

以下说明已有的细节和比较两类；后续加入的场景类型、案例族和分阶段提示见[场景卡说明](scenario-cards.md)。

- **关键细节**：关联一个概念，选出值得保持的条件、公式中的限制、关键步骤或易遗漏的细节。与整个概念的大意解释分别记录。
- **概念比较**：关联 2～4 个概念，围绕适用条件、相似方法的区别或反例提出问题。题面可以主动给出概念名称；这种练习观察辨别能力，不能据此证明能从陌生业务场景自发想到这些概念。

题干、核对答案和出处由本人编写并核对。保存前明确确认已经核对当前资料；这个确认是本人声明，系统不会用 LLM 自动生成或判定唯一正确答案。开放问题可以有合理的替代答案，应核对理由和前提。

编辑、查看旧答案和核对资料属于接触。创建题目后马上作答可以练习，但不能当作经过延迟、未看资料的独立检验。本浏览器会话内的已知资料曝光保守保留；外部阅读仍需要本人如实报告。

## 作答与保存

1. 选择一张可练习的卡，可填作答前的信心，也可以跳过。
2. 先写自己的回答。此时不显示参考答案、旧回答和关联资料。
3. 提交回答后再看核对依据，必要时查看来源正文，记录自评与核对笔记。原答案、事前信心及答题时间已经固定，核对过程不回填原答。
4. 保存本次练习。网络失败保留原请求 ID，可重试；如果进入浏览器待同步队列，必须等同步成功后才会出现在服务端列表和导出中。

「成功 / 部分 / 未成功」是本人自评；没有核对时选择「未核对」。提示与查阅条件分别保留，系统已知的事前曝光不能被后续选择“未查资料”覆盖。事后正常核对不回填为事前曝光，但会影响本会话后续练习的条件标记。

这批记录保存到独立的练习卡与练习记录集合，不计入现有概念解释、场景调用、信心校准、时间表现对照或每日概念复习完成数。所有操作都不改 H、重温起点、长期保持决定或 progressive-kg 正文。

## 版本、暂停和历史

修订、暂停和恢复都追加卡片事件，保留各版本原题及回答。当前统计仅采用当前卡事件且来源版本仍适用的练习；较早版本的记录继续显示在历史中。暂停和恢复不删除题目和答案，也不清除任何概念记忆记录。

任一关联概念的正文版本变化时，卡片显示需要复核，不能直接开始新练习；来源移除时也不能开始。重新核对当前资料，调整题干/答案或来源，再追加修订。旧答案只属于原来的题目与资料版本，不自动迁为新版本成绩。已成功保存的旧请求仍可以得到重复回执；尚未成功的旧版本请求会被拒绝，不能悄悄替换版本。

卡片只关联概念稳定 ID 与来源版本。当前 API 的历史返回这张卡的完整修订和练习集合，首轮适合少量手工问题；大量长期记录的分页与自动任务安排保留为后续工作。

## 数据与接口

SQLite 使用按知识空间隔离的独立练习表。JSON 学习备份增加可选的 `practice: { cards, attempts }`：包括题干、参考答案、出处说明、自己的回答及核对记录，仍不包含原知识库的正文文件、附件或账号凭据。含有工作背景的问题也会进入这个私人备份，选择分享材料时由本人决定。

本轮版本可以预览恢复这些记录，复用既有严格的概念 ID / 路径与版本映射、冲突检查、导入前备份和事务恢复。旧备份没有 `practice` 仍可恢复；旧应用版本无法完整恢复新增练习记录，应使用本轮或更新版本恢复带 `practice` 的文件。

- `GET /api/practice-cards`：当前卡片、来源适用状态及当前版本的最近自评。
- `GET /api/practice-cards/:cardId/history`：该私人卡片的全部版本与练习。
- `POST /api/practice-cards`：创建或追加修订，`previousEventId` 核对当前尾事件。
- `POST /api/practice-attempts`：保存固定题目版本的回答与核对记录。

读写均沿用现有账号与知识空间校验，写入需要会话令牌；读接口不追加学习事件。保存使用固定事件 ID，跨事件类型冲突或修订分叉不会覆盖已有数据。新练习也参与概念历史衔接的“目标已有历史”保护。

1. 创建一张关键细节卡和一张比较卡，确认来源和参考答案；作答前看不到核对答案，提交后可以阅读渲染内容。

3. 在独立测试知识源中修改一个关联概念、刷新索引，确认练习卡要求复核；不要为了验收修改自己的生产笔记。

自动检查覆盖的是记录正确性和流程边界。题目质量、视觉效果、真实延迟回忆以及辨别能力的收益仍待本人试用；本批完成不代表原 LM-010/LM-011/LM-012 已整体完成。
