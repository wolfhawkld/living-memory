# 节点回忆变化追踪

更新：2026-09-27。接续 P0-5 / LM-018 的个人观察准备，在节点上查看同一资料版本前后两次练习，不新增评分或遗忘模型参数。

## 使用入口

在真实学习记录模式选中节点，展开右侧「回忆变化追踪」。默认收起，概念解释与场景调用分别展示：

- 前一次和最新一次作答的时间、提示方式、资料曝光、事前信心。
- 概念解释显示清晰/模糊/想不起自评；场景调用显示核对结果及依据。
- 每条记录保存时的距重温间隔、H 与参数版本。
- 两次作答的真实间隔、当前版本的记录总数，以及所报条件相同、不同或不明的提示。

只显示一条记录时提示尚缺前一次；没有记录时显示空态，不模拟进步。查看本区域不展开原回答，也不触发资料曝光。回忆和场景任务进行中沿用已有历史遮蔽规则。

图谱时间预览期间，这里仍展示真实保存的观察，并明确提示与预览时间分开。

## 如何理解对照

对照固定取每类任务最近两条记录，不跳过最近一次去寻找成绩更好或条件更接近的早期记录。排序按作答时间、保存时间、记录 ID 依次确定；补记旧观察不会顶替较新的作答。

所报条件比较使用提示方式和有效曝光状态，场景还比较核对依据。系统已记录看过资料时，优先按曝光处理；缺失条件保留“不明”。“所报条件相同”只描述已有字段，不证明题目难度、场景、近期接触或其他条件相同。

两次作答间隔不等于无接触的保持时间；期间可能阅读、工作应用或再次学习。当天重复练习与经过真实时间的后续检验都保留原时间，不自动命名为独立延迟实验。事前信心只表示当时的自我预测，不能替代核对结果。

本项不计算进步分数、预测误差或记忆改善幅度，不更新 H、重温起点、长期保持或复习安排。完整 LM-018 仍需本人完成基线、后续检验、接触条件与任务负担反馈。

## 数据与兼容

`GET /api/concepts/:conceptId/history` 新增可选 `progress`，包括当前概念/资料版本/读取时间、两类任务各自的最近两条元数据、计数和排除数量。它按概念完整历史计算，不受普通历史分页或修正记录精确定位影响。

旧资料版本只计入排除数量；无效时间、未来作答或未来保存记录不进入对照。没有 `learning` 的旧观察归为概念解释，其提示方式和核对信息保持未知。未记录、晚于作答或格式不合法的信心预测不当作事前信心。

返回数据逐字段选取，不包含原回答、业务场景、适用性说明或知识正文。继承当前账号与知识空间隔离，不新增表或数据库迁移；保存、导出和恢复原事件的格式不变。旧服务缺少 `progress` 时提示更新服务，不显示为零条记录。前端检查概念、资料版本及读取时间一致性，并继续丢弃取消或切换后的迟到响应。
