# 图谱主题（THEME-04）

更新：2026-09-26。状态：代码与自动验证已完成，浏览器视觉验收待用户进行。协作任务：[Issue #35](https://github.com/wolfhawkld/living-memory/issues/35)。基于 THEME-03 的 `feat/theme-workspace`，本轮分支为 `feat/theme-graph`。

## 使用方式

在工作区「主题」中选择深色、浅色或跟随系统，3D/2D 图谱随页面一起切换。背景、节点、空心环、连线与箭头、屏幕标签、悬停提示、图例和降级文字列表均使用有效主题。六种记忆状态含义不变，页面与图谱共享状态配色。

浅色采用淡灰蓝背景和较深的状态色；选中环、相邻关系和完整名称仍突出显示。未知状态继续用空心环，其余节点的状态色不会被选中颜色覆盖。长名称继续沿用已有缩写、折行和标签避让规则。

「发光效果」仍控制局部光晕与节点自发光。浅色使用普通透明混合，关闭全场景 Bloom，避免淡色背景泛白；深色恢复原有加色光晕和 Bloom 参数。主题切换保留用户的发光开关选择。

## 更新与生命周期

- `theme-palette.ts` 提供完整 `DARK_THEME` / `LIGHT_THEME`，浅色状态值与页面共用。删除 THEME-03 的图谱强制深色边界，覆盖层继承根主题。
- `GraphView` 读取有效主题，通过 ref 将最新配色传入节点创建、关系/箭头回调和标签帧更新。主题不进入实例 key 或图谱数据 memo，也不重新提交 `graphData`。
- `graph-theme.ts` 原地修改已有节点材质、背景颜色对象和灯光；几何、纹理及后处理 pass 均复用。Bloom 与 OutputPass 一起启停：关闭时由直接输出到屏幕的 RenderPass 完成颜色空间输出。
- 连线使用底层库的颜色/透明度 API，保留库的材质管理。已停稳布局不会因此重新预热；库可能再次通知 engine-stop，因此仅初始布局或拓扑变动触发布局保存，拖拽仍通过原入口保存。
- 标签缓存签名包含实际配色，主题切换复用同一 DOM、标题、位置与尺寸。悬停提示通过主题 CSS 更新。
- 相机聚焦、缩放、当前选择、2D/3D 模式及旋转时钟沿用原逻辑；人工切主题会触发现有的人工操作暂停旋转规则。系统外观变化不会伪造人工操作。

主题不参与记忆投影，也不写学习记录。后续 THEME-05 已接入 [Mermaid 图表和图片容器的主题](theme-media.md)，本文件保留 THEME-04 的实现与验证记录。
