# 学习数据导入恢复

更新：2026-09-27。对应 LM-006 的学习记录恢复子集。

## 使用

真实记录模式的顶部提供「导出学习数据」与「导入恢复」。先同步浏览器中的待写入记录，并继续或结束未完成的复习，然后选择之前导出的 JSON 文件。

1. 选择文件，查看目标账号；布局和复习安排默认不恢复，可按需勾选。
2. 生成预览，核对新增/重复记录、概念对应关系、无法关联的历史、配置变化以及冲突提示。
3. 勾选已核对，确认导入。预览本身不写入学习记录。
4. 成功后展示回执及导入前备份标识，图谱和复习安排重新读取恢复结果。窗口可直接关闭；刷新超时会提示重新加载，期间暂停布局自动保存，防止旧坐标覆盖恢复结果。

文件限 20 MiB、50,000 条学习事件、10,000 个概念元数据及布局条目。仅支持现有 schemaVersion 1 导出；示例演示文件不属于学习备份。当前功能不包含 Markdown 正文、附件、知识关系、账号密码或浏览器里的待同步记录/复习草稿；换机器时需另行复制知识库。

## 恢复规则

- 目标始终为当前登录账号的知识空间，备份中的来源标识不能切换账号或指定磁盘路径。
- 优先匹配概念 ID；相同 ID 的文件路径不同会阻止导入，除非本机已通过「历史衔接」确认这两个路径属于同一概念。换根目录导致 ID 变化时，只允许唯一的「相对路径＋内容版本」对应，并在预览明确列出。
- 不按名称猜测概念。暂时找不到对应文件的历史保留原 ID，可再次导出；不会因此在图谱上创建节点。改名/移动后可使用[人工历史衔接](concept-identity.md)。
- 事件 ID、原发生/记录时间、回忆表现、曝光条件及当时冻结的时间指标保留。导入不新增一次“今天重温”，也不自动解除长期保持。
- 与当前记录相同的事件跳过；同 ID 不同类型/内容、无效引用、长期保持链分叉或配置版本冲突会阻止整批导入，不提供强制覆盖。
- 可选的知识修正复核记录随应用/总结一并恢复，保留原决定、说明和检查版本。父应用可以来自当前数据或同一备份；处理链必须接在现有尾部，缺失引用、跨应用前序、分叉或环会阻止导入，预览单独列出新增数量。
- 配置历史按 revision 合并；同 revision 的模型与 H 必须一致。备份包含兼容的新版本时，当前 H 会随之更新，预览会显示前后值。回忆观察仍使用各自冻结的配置。
- 勾选布局时合并坐标，同概念以备份为准。勾选复习安排时采用备份的每日预算并合并节点偏好，同概念以备份为准；本地安排 revision 按实际变化递增。

新的 v1 导出附带可选 `restoreMetadata`，保留重温请求是否省略发生时间，以及配置记录时间。旧导出仍可恢复；缺失元数据时会明确提示，无法保证旧的“省略时间”请求恢复后的原样重试，应使用新导出做日常备份。

导出中的可选 `identityBindings` 仅用于审计，不会在导入时创建绑定，也不能授权不同路径的身份对应。历史路径许可只读取当前知识空间中已经人工确认的本地登记。

## 一致性与备份

`POST /api/import/preview` 与 `POST /api/import/commit` 均要求登录、本地写入令牌及当前知识空间标识。预览只返回计数、概念元数据和问题，不返回回忆答案或应用正文。

提交会在 SQLite 事务内重新核对文件、选项、当前记录及概念索引；预览之后有其他窗口/CLI 修改了数据时，需要重新预览。确认写入前自动导出当前账号的数据，保存在数据库目录的 `import-backups/<空间摘要>/<文件>.json`；文件权限为 600。备份失败则不写入，数据库错误则整批回滚。

同一次提交使用固定 importId。断网后可以原样重试：服务端持久化回执，已提交成功的请求直接返回原结果，不会重复新增事件或备份。相同 importId 换了文件/选项/预览标识会被拒绝。

## 验证范围

自动验证覆盖格式、匹配、冻结指标、冲突、旧格式、命名空间隔离、事务回滚、预览过期、幂等回执与导入前备份；仅使用临时数据库和合成知识源，不导入个人真实数据。浏览器视觉验证交给用户。

本轮 370 项 Node 测试、`npm run build` 和 `npm run check:theme-build` 通过；未运行浏览器或 Playwright。

上一项「复习安排与中断续做」的浏览器试用按用户要求跳过，保留未验收状态。
