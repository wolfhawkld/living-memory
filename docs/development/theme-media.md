# Mermaid 与图片主题（THEME-05）

更新：2026-09-26。状态：代码与自动验证已完成，浏览器视觉验收待用户进行。本轮按用户要求改为在长期开发分支 `develop` 上继续迭代，承接此前 THEME-01～04 和其他功能的连续提交，不单独创建任务 PR。

## 当前行为

- Mermaid 图表随有效主题重新渲染：深色使用 Mermaid 的 `dark`，浅色使用其内置 `default`；跟随系统也使用同一路径。工具栏、源码、缩放、加载与错误提示同时适配。
- 换主题保留图表缩放、原代码/图形选择与滚动位置。旧图保持显示，替代 SVG 预加载完成后才换图；图片尺寸显式保留，减少替换时的视口收缩。更新提示不占据文档流，避免阅读位置因工具栏高度变化而跳动。
- 配色更新失败时保留上一张可读图并给出重试入口。更换图表源码才重置该图的阅读控件，旧来源的图不会显示在新来源下。
- 普通图片只调整容器、边框、说明和错误提示；原图不反色、不改写 URL。原始尺寸/适应宽度选择不随主题重置，主题变化本身不会重新请求附件。

## 队列与资源

`mermaid-renderer.ts` 在任务入队时捕获主题、API、ID 和取消信号，初始化与渲染始终位于同一串行队列。按 API 记录上次成功初始化的主题；初始化失败会使缓存失效，后续任务重新配置。源码配置清理、strict 安全级别、字符/边数限制、SVG 校验及临时容器清理继续生效。

快速切换会取消过时请求；尚未开始的任务跳过渲染。已经进入 Mermaid 的计算仍等待完成并清理临时容器，其结果不会覆盖新主题。

`mermaid-preview.ts` 管理预览请求与 Blob URL：创建前和图片预加载后检查请求版本，过时预览立即释放；旧显示 URL 留到 React 提交替代图后再释放。关闭阅读窗口时取消请求并释放全部预览；同一控制器清理后仍可重新加载，以适应 React 开发模式的 effect 重放。

主题展示不修改知识正文、个人记忆、学习历史或图谱布局。
