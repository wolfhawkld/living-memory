## 用户试用清单

1. **偏好恢复**：在匿名页与登录后分别选择主题，刷新、退出再登录；选择「跟随系统」后切换系统外观。另开同账号标签页切换主题，检查当前页同步。预期选项与实际颜色一致，匿名与账号互不继承；有其他账号时可补查账号间隔离。
2. **图谱与镜头**：分别打开小领域和数学等大领域，选中一个节点、调整视角后切换深浅主题；在 2D、3D 下各做一次，顺便切换发光和跨域展开。预期布局、选择、模式和镜头保持，全屏显示正常；人工操作仍暂停旋转，空闲两分钟恢复。
3. **记忆语义**：对照图例查看真实状态、示例状态与未来预览。未知、近期、建议再访、较久未访、待确认、长期保持应继续可辨认；换主题不新增学习历史、不改变重温时间。
4. **工作区与阅读**：搜索长名称、查看历史、打开 Markdown 大窗；在尚未提交的回忆/场景练习里填写回答与信心后换主题。预期文字清楚、长内容可以内部滚动、草稿和阅读状态保留。检查错误与待同步提示可等自然出现，无需人为制造失败。
5. **媒体（此前暂停，保持待测）**：以后恢复图片/Mermaid 测试时，再检查同页多图、缩放滚动后快速换主题、源码视图切换，以及关闭重开；透明/深底图片需单独观察。
