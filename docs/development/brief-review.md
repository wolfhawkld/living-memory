# 少量复习入口（LM-012 的 P0 子集）

更新：2026-09-27。当前实现沿用时间驱动模型，把少量回忆练习接到图谱状态上；已增加[重点、暂缓、每日预算与中断续做](review-arrangements.md)，不引入新的遗忘率拟合或自动评分。

## 使用方式

1. 切换到「真实学习记录」，时间预览回到「实时状态」，选择要复习的知识域。
2. 左侧搜索框下方的「少量复习」可选择本轮最多 **3 个或 5 个**概念，默认 3 个，同时受每日剩余预算限制。候选不足时使用实际数量；没有候选时给出说明，不凑数、不弹出催促。
3. 点击「开始复习」。每条先预测信心、用自己的话回答，再提交回答查看资料、核对与自评。题目会说明推荐依据以及重温时间是否为估计。
4. 点击「保存这次观察」后显示本条结果和进度。观察仍进入对应节点的学习历史与信心汇总，**不会自动更新重温时间**。实际完成重温后，可以另行点击「确认本条已重温」。
5. 点击「下一条」继续；可「跳过本条」、「暂停，稍后继续」或「结束本轮」。暂停和刷新保留当前浏览器的作答与进度，结束会丢弃未提交作答。保存或加载期间短暂禁用离开，避免同时进行互相冲突的操作。

## 透明的候选规则

- 从当前目录领域的完整真实快照选取，包含图谱显示上限之外的概念，不混入跨域展开节点。
- 仅选择 `revisit`（建议再访）或 `stale`（较久未重温）。现有模型在距重温达到 H 时进入再访阶段、达到 2H 时进入较久未重温阶段；H 是当前全局时间提示参数。
- 候选必须具有与当前概念和内容版本匹配的重温起点，以及有效的时间数值。
- 排除手动长期保持、未知、待确认、近期重温以及有本地待同步记录的概念。没有可靠起点的知识仍可在节点详情中手动回忆、阅读或确认实际重温。
- 有效暂缓中的概念不进入候选；手动重点优先，同组按距重温时间从长到短、概念 ID 排序。估计重温也可进入候选，但题目明确标注。重点不会绕过长期保持或可靠起点要求。
- 当前浏览器时区内，今日已保存概念回忆的节点不重复推荐；与今日待同步观察合并去重后，限制本轮数量。手动回忆仍可随时进行。

这是一种安排练习的工程规则，不是对个人回忆成功率的测量。信心、观察结果和场景调用表现继续独立保存，本轮不把它们加权成新的推荐分数。

## 会话、同步与数据边界

- 开始本轮前刷新真实状态；本轮的候选 ID、内容版本和顺序固定，不因单条保存而补入更多题。
- 每次进入下一条前重新读取真实快照。候选被删除、内容或领域变化、已重温、设为长期保持或出现待同步记录时，按不可用跳过，不替换成别的题。
- 作答期间遮蔽知识列表、图谱、详情与旧回答；核对阶段才显示当前资料。已有的资料曝光标记继续有效，不会把即时重做伪装成未看过资料的回忆。
- 会话绑定当前账号知识源；期间锁住领域、示例/模拟和知识源刷新等操作，后台快照更新延后。深浅主题切换不清空作答；发生来源变化时保留退出入口并停止继续提交。
- 保存失败时保留原回答和固定事件 ID，重试不重复创建观察。网络失败且成功写入本地待同步队列时，可继续下一条；进度中的「已入待同步」表示本轮曾入队的观察数，不代表已被服务端接受，也不等同于当前未同步总数。
- 推荐、跳过和结束不创建学习事件。只有明确提交观察或确认重温才走现有写入接口；确认重温也沿用幂等重试和待同步处理。
- 队列和未提交作答保存在当前浏览器，绑定当前私人知识源。刷新后由本人点击继续，恢复前重新核对内容、领域、起点、暂缓和长期保持状态。暂停不会新增学习事件，明确结束或放弃才删除本轮断点。跳过仍只作用于本轮；较长的暂缓在节点详情设置。

## 检查与范围

逻辑检查覆盖候选的领域/时间边界、长期保持及待同步排除、排序/预算、队列接续、过时回调和下一条的资格重验。临时知识源与数据库的 API 集成检查验证观察与重温的不同影响，以及重复提交的幂等性。

- `npm test`：**288/288 通过**，本轮新增 10 项（候选 3 项、会话 5 项、API 集成 2 项）。
- `npm run build`、`npm run check:theme-build`：通过，保留既有图谱大包提示。
- 代码复核补齐启动请求期间的交互锁：等待候选返回时不能另开普通回忆或保存参数，防止新返回的首题覆盖草稿；题间加载沿用同一锁。
- 浏览器操作与视觉由用户验收，本轮不运行自动浏览器测试。

建议试用：有真实再访候选的领域开始一轮，依次试保存观察、跳过、提前结束；查看观察保存前后节点重温起点保持不变，再单独确认重温观察起点更新。没有候选时无需伪造个人学习日期，可使用节点原有的手动回忆入口。
