# 主题选择与本机偏好（THEME-02）

更新：2026-09-26。对应[浅色主题计划](../planning/light-theme-todo.md)第二项；协作任务 [Issue #31](https://github.com/wolfhawkld/living-memory/issues/31)。

## 当前可以使用什么

- 登录、首账号创建和会话检查页面的卡片下方，以及工作区「真实学习记录 / 示例状态」一行右侧，提供「主题」下拉框。
- 可选择深色、浅色或跟随系统。跟随系统时旁边显示当前解析为深色还是浅色；无保存偏好时默认深色。
- 登录/初始化页面和主题控件已接入浅色；[THEME-03](theme-workspace.md) 已补齐工作区主体、账号与学习弹窗和 Markdown 阅读层，[THEME-04](theme-graph.md) 接入图谱画布、标签与覆盖层，[THEME-05](theme-media.md) 接入 Mermaid 与图片容器。整套浏览器视觉验收仍待用户进行。

## 偏好与账号

使用浏览器 `localStorage` 保存简单的 `dark / light / system` 字符串：

| 作用域 | 键 |
| --- | --- |
| 匿名、初始化、登录、会话检查/错误、无账号旧模式 | `living-memory.theme.v1:anonymous` |
| 已认证账号 | `living-memory.theme.v1:user:<编码后的账号 ID>` |

账号无偏好时使用默认深色，不继承匿名或其他账号；退出后恢复匿名偏好，切回原账号恢复自己的选择。同一账号切换知识域、用户名改变或访问修订号变化不会创建新偏好。其他标签页修改当前作用域的偏好时同步显示；其他作用域的更新不会改变当前选择。

本机偏好不影响身份认证，不含密码、会话令牌或知识内容。读取失败、写入失败和浏览器禁止存储时，当前页内的选择仍有效；离开并返回同一账号也保留这次页面运行中的选择。刷新后是否保留取决于浏览器是否允许持久化。首版不提供跨设备主题同步。

## 接入与生命周期

- [theme-preferences.ts](../../src/web/theme-preferences.ts) 管理作用域、偏好校验与稳定快照，不依赖 React、DOM、API 或学习存储。
- [ThemeProvider.tsx](../../src/web/ThemeProvider.tsx) 覆盖 AuthGate 的全部分支，使用已验证账号 ID 选择快照。主题变化不作为 React key，不重建 App 或 GraphView。
- [theme-bootstrap.ts](../../src/web/theme-bootstrap.ts) 经 Vite 注入同步 head 脚本，在 React 加载前只恢复匿名主题，并设置 `data-theme`、`data-theme-preference`、`color-scheme` 和浏览器主题色。不保存“上次账号”作为身份提示；认证完成后通过布局 effect 在私人工作区绘制前应用账号偏好。
- 系统外观监听只在当前选择为 `system` 时启用，退出该选择或卸载时清理。再次进入跟随系统时读取当前系统状态，避免使用先前缓存；本机存储监听随 provider 生命周期清理。
- 人工操作主题下拉沿用现有页面活动监听，暂停图谱自动旋转；系统或其他标签页导致的主题更新不伪造人工输入。相机、节点选择、布局、模式和答题草稿不由主题控制器更改。

浅色 UI 基础色保存在公共配色模块的 `LIGHT_UI` 中，完整 `LIGHT_THEME` 提供页面与图谱共用的六种状态色；`theme-workspace.ts` 补充组件语义变量。浅色根变量覆盖完整页面和图谱覆盖层，组件保留原深色回退值，场景材质按有效主题原地更新。
