# 知识域视图

知识域切换解决的是“知识库持续增长后图谱过密”的阅读问题。系统把知识源分成两个层次：服务启动或刷新时建立一个包含全部概念和全部已解析关系的完整索引；客户端再从索引投影当前领域的可读图谱。完整索引常驻内存，领域投影只限制当前渲染范围。

## 范围和配置

`LM_KG_INCLUDE` 是相对知识根目录的目录前缀。它继续影响缺省的 `/api/snapshot`，同时为 Web 提供推荐的初始领域。没有匹配项时，Web 根据自身的可用领域选择初始项。

`LM_KG_LIMIT` 是每个领域的主节点显示上限，范围为 1 到 300。它限制图谱投影，不代表完整索引、CLI 查询或知识源的容量上限。缺省 `/api/snapshot` 保留旧的前缀和数量语义，供兼容调用使用；Web 和 CLI 使用 `/api/snapshot?scope=all` 获取完整概念、关系和记忆状态。

目录领域 ID 由概念的 `source.path` 计算：统一斜杠后取规范化父目录，例如 `Cognition/Math`；根目录笔记使用 `__root__`。这个 ID 用于切换和持久化选择，笔记 frontmatter 中的 `domain` 仍可用于内容展示，但不改变目录领域 ID。

## Web 行为

Web 首次加载完整索引，列出可用目录领域和每个领域的概念数，并按知识源记住上次选择；没有可用的历史选择时使用来源提供的初始领域。切换领域时，图谱显示该领域的主节点，最多使用 `LM_KG_LIMIT` 个；左侧搜索仍针对当前领域的完整索引，可定位超出当前图谱主节点上限的概念。选中这样的概念后，它会替换末尾的一个主节点，保持显示上限。

选中节点后，详情区域显示跨域关联。跨域入口只展开一层直接关联，最多展开 6 个节点，当前投影总数最多 300 个。展开后可收起；“前往该领域”会切换到目标目录并定位到关联概念。跨域展开是临时的视图操作，不会创建学习事件。

领域切换和跨域展开不改变概念 ID、来源版本、时间起点、记忆状态颜色、观察记录或其他学习记录。它们只改变哪些节点当前可见；服务刷新后仍从同一份完整索引和同一份学习库重新投影。

## CLI 和其他入口

CLI 的 query、show、status 和 review 都读取完整 scope。查询可跨领域搜索；show、status 和 review 可以使用完整索引中的概念选择器。CLI 不依赖 Web 当前选择的领域，仍通过 source ID 校验知识根目录，并与 Web 共用本地学习记录。

progressive-kg 的收尾钩子调用刷新接口。刷新会重新建立完整索引，再由 Web 根据当前领域重新投影；刷新本身不会把查询、生成或文件变化当作重温事件。

## 布局和性能边界

布局以概念 ID 为键保存。Web 切换领域时只提交当前视图产生的局部坐标，服务端会与已有布局合并，因此保存另一个领域的节点不会清除隐藏领域的位置。布局数据和学习记录都按知识源命名空间隔离。

完整索引目前会把知识源中的概念和关系加载到内存；`LM_KG_LIMIT` 与跨域节点上限只约束渲染投影，不构成大规模知识库的内存、布局或 GPU 性能保证。桌面端真实体验、动画流畅度和数据规模边界需要在目标设备上验证。本轮不由 Agent 执行浏览器视觉验收，由用户自行检查。

## 本轮验证

对应 [Issue #5](https://github.com/wolfhawkld/living-memory/issues/5)，属于 LM-013 / LM-016 的先行子集。

- `npm test`：85 项通过，包含领域投影、显示上限、跨域索引、默认范围以外的 CLI 查询与明确重温、局部布局合并和原有回归测试。
- `npm run build`：通过，包含 TypeScript 检查。Three.js 主 bundle 的体积提示仍存在。
- 本地知识源通过 HTTP 快照和 CLI 查询验证；启动新版服务及查询前后，数据库中全部已有学习、参数与布局记录相同。同一时间的兼容范围快照与完整快照具有相同节点状态。
- 已适配原有浏览器测试的领域范围与选择器；本轮未启动浏览器或执行这些用例，交互与视觉验收由用户完成。
