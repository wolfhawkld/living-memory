# 运行时间驱动原型

本原型实现 `time-only-v0`：一个全局 H，学习/重温确认建立时间起点，查询和回忆观察不改变曲线。知识源会建立完整的内存索引，Web 再按目录领域投影当前图谱；完整 v0.1 的语音、场景任务和 Obsidian 尚属后续工作。领域投影的详细契约见[知识域视图](domain-views.md)。

## 环境与启动

使用 Node.js 22.13 或更新版本，建议与当前验证环境一致的 22.23.1。内置 `node:sqlite` 在 Node 22 仍显示实验性提示；本原型通过独立本地服务使用，不依赖浏览器/Obsidian 的 Node 版本。

```bash
npm ci
npm run build
npm start
```

打开 `http://127.0.0.1:4317`。服务仅监听本机。默认载入仓库内的合成知识源，没有预先设置的个人学习记录。

若页面显示待同步项，点击「重试同步」后查看左侧「待同步详情」中的记录类型、错误信息和错误码。该信息会保留到下次打开，帮助区分服务不可达、记录冲突和浏览器存储问题；处理边界见[待同步记录与错误定位](pending-sync.md)。

首次打开进入明确标注的“示例状态”，用虚构时间间隔展示不同颜色。可展开初始数值、拖动时间轴、导出模拟记录；点击“查看真实记录”开始真实学习操作。详细数值、记录位置与连线说明见[时间颜色与连线](time-colors-and-links.md)。

图谱默认启用发光效果，可用顶部“发光效果”开关关闭。长节点文字自动折行，超出显示行数时省略；悬停节点或查看右侧详情可读完整名称。

图谱维度使用「3D 纵深 / 2D 阅读」两个互斥的分段按钮，默认选中 3D；按当前模式高亮，同时提供 `aria-pressed` 状态。文字列表下禁用维度切换，返回图谱后沿用此前的模式。

进入 2D 会重新定位到图谱平面，背景左键拖动平移、滚轮缩放，禁用空间旋转。2D 使用临时阅读布局，不覆盖已保存的 3D 坐标；模式切换重新定位镜头，选中概念与学习记录继续保留。详见 [2D 阅读的坐标与镜头](2d-graph-view.md)。

开发时使用 `npm run dev`，打开 `http://127.0.0.1:5173`；前端代理 API 到本地服务。启动新模式前关闭旧实例，避免端口冲突。

## 接入自己的 progressive-kg

知识源由启动环境指定，原知识库只读。以下示例假定两个项目相邻；按实际位置修改路径：

```bash
LM_KG_ROOT="../progressive-kg" LM_KG_INCLUDE="Cognition/Math" LM_KG_LIMIT=100 npm start
```

PowerShell 可以先设置环境变量，再启动：

```powershell
$env:LM_KG_ROOT = "C:\path\to\progressive-kg"
$env:LM_KG_INCLUDE = "Cognition/Math"
$env:LM_KG_LIMIT = "100"
npm start
```

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `LM_KG_ROOT` | 仓库 `fixtures/demo-kg` | 只读知识根目录；指定错误时不会回退为示例 |
| `LM_KG_INCLUDE` | 不限定 | 兼容缺省 snapshot 的相对目录前缀，也作为 Web 的初始领域提示 |
| `LM_KG_LIMIT` | 20 | 每个领域的主节点显示上限，原型上限 300；不限制完整索引 |
| `LM_DATA_DIR` | `data/local` | 私人学习库目录，默认已被 Git 忽略 |
| `LM_PORT` | 4317 | 本地服务端口 |

服务会扫描并在内存中保留完整索引；`LM_KG_LIMIT`只限制每个领域的主节点投影。目录超过该上限时仍可通过左侧全库搜索、节点选择和跨域入口访问完整索引中的概念。搜索结果可跨领域跳转定位；仅输入关键词不会选中节点。调整来源目录或 `LM_KG_INCLUDE` 仍需要重启服务并刷新页面；只改变显示范围不会重建已有学习历史。

默认 `/api/snapshot` 保留旧的范围视图，受 `LM_KG_INCLUDE` 和 `LM_KG_LIMIT` 影响；Web 和 CLI 使用 `/api/snapshot?scope=all` 获取完整索引。目录领域 ID 取概念来源路径的规范化父目录，根目录笔记使用 `__root__`。Web 按当前领域显示主节点，并允许从选中节点展开单层跨域关联；具体上限和跳转行为见[知识域视图](domain-views.md)。

浏览器和服务可以位于 Windows/WSL 的不同侧，但由服务读取其能访问的路径；浏览器不直接扫描本机目录。若本机不能通过回环地址跨环境访问，先把服务和浏览器放到能互通的运行环境；此原型不自动开放到局域网。

## 第一次体验

1. 选择一个概念。没有可靠重温日期时显示“未知”，不会从笔记修改日期推断。
2. 可以先想一句，也可以直接查看资料。资料默认折叠；查看过的内容会影响本次观察的提示标记。
3. 真正完成重温后，点击确认按钮；也可补记过去的日期，并明确标为用户估计。
4. 用模拟时间条查看若干天后颜色如何变化。模拟时禁止保存重温或回忆观察，返回真实时间后再操作。
5. 可选记录“能解释／有些模糊／想不起”。自评不会改变 H 或重温起点。
6. 关闭并重开，确认记录仍在；需要留档或离线分析时，使用「导出学习数据」下载 JSON。当前没有 JSON 导入恢复入口，导出文件不是可直接恢复整个应用的备份。

H 默认 7 天，是工程起点，不是测出的个人遗忘参数。时间指标不是回忆正确率，不表示忘掉了多少知识。建议首次观察期间固定 H；调整参数有版本记录，观察保留作答时的参数。

## 首轮试用怎么观察

知识资料支持 [Markdown 与大窗阅读](markdown-reader.md)：选择概念后点击“打开大窗阅读”，在大窗口查看渲染后的正文或摘要，使用 A− / A＋ 调节字号；Esc 关闭。回忆作答前资料继续隐藏，提交答案后可打开大窗核对。

节点详情现在提供[逐概念学习历史](concept-history.md)：关闭示例状态后，可查看确认重温、估计补记和回忆观察，识别当前时间起点。旧回答需要主动展开；进入新回忆任务时历史隐藏。历史读取和答案展开不重置曲线，观察数值保留当时的参数。

先用 10–20 个熟悉概念，按真实阅读和工作节奏使用。未知节点可以保留未知；不要为了填满颜色而批量确认重温。遇到愿意检验的概念时，先写一句解释，再查看资料并记录自评。只有实际完成了重温，才另行确认重温时间。

观察重点是：时间颜色是否帮助你找到值得重新看的知识，额外操作是否足够轻，以及时间估计与实际回忆在哪些概念上明显不一致。首次体验可以立即反馈界面问题；回忆的变化需要经过真实时间，模拟时间不能替代延迟观察。

私人观察可记在被忽略的 `data/local/trial-notes.md`，例如：

| 日期／概念 | 距确认重温天数 | 是否提前看过资料 | 实际回忆／遗漏 | 时间颜色是否有帮助 | 操作负担／待改进 |
| --- | --- | --- | --- | --- | --- |
| 自行填写 | 以界面为准 | 是／否／不确定 | 一句话即可 | 有／无及原因 | 一句话即可 |

先依据观察决定是否需要区分概念难度、内容细节或应用场景，再增加模型变量。

## 数据与边界

学习记录保存在服务的数据目录，按知识根目录隔离；切换领域、示例/真实知识源不会相互填入历史。导出包含当前知识源的概念 ID/标题/来源引用、已同步的重温与回忆观察记录、当前参数及参数历史、布局。不包含知识正文、图谱关系、浏览器中的待同步队列或布局恢复备份；这些内容不能靠该 JSON 恢复。导出读取当前知识源的完整已同步数据，不受所选领域或时间预览限制。原知识库不会被改写。领域切换只改变图谱投影；时间起点、颜色状态、观察记录和其他学习事件保持共享。

图谱布局按节点 ID 保存。Web 提交当前领域的局部坐标时，服务会与已有布局合并，因此切换领域或保存另一个领域的节点不会清除隐藏节点的位置。

P0 的概念身份由知识源与相对路径确定。正文变化会让旧记录显示待确认；重命名目前产生新身份，需要后续人工重联支持。原型不自动继承未知身份，也不实现完整 v0.1 的拆分/合并及导入恢复界面。需要完整备份时先关闭服务，再备份整个数据目录与原知识库。

## 检查

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

单元/服务测试使用临时数据库和合成材料，浏览器测试使用独立临时学习库，不修改个人知识文件或日常学习库。浏览器测试前需要完成 build；测试使用 4318 端口，独立于日常原型的 4317 端口。

Linux 若缺少 Chromium 系统库，可运行 `npx playwright install --with-deps chromium`，安装系统依赖需要相应管理员权限。

软件渲染的自动浏览器测试只能验证交互与基本 WebGL 路径，不能作为实际桌面 GPU 帧率/功耗结论。当前完整索引会加载到内存，领域投影的节点上限只约束渲染范围，不构成大规模知识库的性能保证。真实短期试用用于观察体验和模型误差，不等于已经证明学习收益；本轮浏览器视觉验收由用户进行。
