# 用飞书开始日常复习

更新：2026-10-13。本页说明当前已有功能的用法，不要求人工维护题库。真实按钮往返、学习写回和长期效果继续由本人试用；软件回归不能代替这部分验收。

## 先走通一个概念

1. 确认本机服务正在运行、联网且电脑不会休眠；手机通过飞书即可使用，不需要和电脑同一局域网。仍只运行一个 Living Memory 飞书连接器。
2. 在 Web 的真实记录模式，左侧「少量复习 → 复习安排」设一个适合自己的正数预算。可先用 3 个；这是建议，不会自动修改个人设置。
3. 在已绑定的机器人私聊发送 `知识 待复习`，选一个候选的「回忆 N」。也可发送 `知识 复习` 从首个候选开始。
4. 看到概念名后，先在脑中说明它的原理和一个适用场景，再点「查看资料」。对照后选择「清楚 / 模糊 / 想不起」，评价的是打开资料前的回忆。
5. 等待自评保存回执。确实完成重温后，再单独点击「确认已重温，更新时间」。自评本身不会重置时间起点。
6. 回 Web 查看同一个节点的学习历史：脑中自报与明确重温应分别显示。先验证这一条，再按下方每周节奏少量使用。

卡片操作会发送新卡，请使用最新一张。按钮提示不等于学习写入已经成功；没有收到新卡时发送 `知识 继续复习` 查看原会话，避免反复点击旧按钮。

## 当前试用安排：每周 3 个概念

2026-10-13 调整：考虑本机不一定每天开机并运行服务，先按每周 3 个概念试用，不要求每天更新进度。

- 每周有条件时启动本机服务，发送一次 `知识 复习 3`，按实际候选完成少量回忆、自评和独立确认重温；候选不足就按实际数量进行。
- 尽量在这次使用中完成或结束本轮，不把一份未完成会话留到下周。会话最多保留 24 小时；已经保存的学习记录独立保留。
- 某周没有条件使用就顺延，不要求补齐数量。下次启动按实际距离上次确认重温的时间重新投影，关机期间不需要后台持续计算，也不会自动补造学习记录。
- 当前设置仍是「每日预算」，没有每周配额或自动周重置；每周 3 个是本次人工试用节奏。`知识 复习 3` 表示当前批次最多 3 项，不代表每周限制。本次安排不自动修改个人预算或遗忘参数。

## 单次使用的最小流程

- 发送 `知识 复习 3`，最多处理 3 个现有候选。自评后可点「下一条」；最后点「完成本轮」。候选不足会减少实际数量。
- 来不及就发送 `知识 暂停复习`，回来发送 `知识 继续复习`。卡片有效期为 30 分钟，会话最长 24 小时，暂停不会延长寿命。
- 某一项暂时不想做可跳过，不扣完成数；不要求把历史欠账清空。预算设为 0 时新题持续暂停，调高后恢复。已有当前题和待写记录保留。
- 想集中在一个知识域：发送 `知识 卡片 领域`，在领域的待复习入口选择本轮 3 / 5 项。`知识 复习 3` 本身使用全域候选。

没有候选时，先看卡片提示中的预算、日期和时区。未知重温起点、资料版本变化、近期重温、本人固定长期保持、暂缓或当天已完成的节点不会自动加入。可用 `知识 卡片` 浏览，或 `知识 卡片 搜索 概率` 搜索名称和别名。

对于尚无时间起点的概念，当前飞书不能从任意阅读卡直接确认重温；可在 Web 真正学习该节点后「确认已重温」，以后按时间条件进入候选。不要为了凑测试候选补造过去日期。

## 飞书和 Web 的分工

飞书适合短时脑中回忆和本人确认重温，保存为概念任务的脑中自报：没有书面原答、事前信心预测或自动评分。因此它不会被统计为独立场景调用成功或信心校准样本。

工作中遇到“认得概念，却没想到该用它”的真实问题时，再回 Web 做场景调用与事前信心记录，保留原问题、候选和依据。这样日常不必维护卡片，较完整的记录集中在确实有价值的工作场景。

按每周 3 个的节奏逐周观察操作是否顺畅、单次负担是否合适、哪些概念反复模糊。记录实际间隔，不把不规律使用当作连续每日训练；少量试用不据此认定遗忘曲线已经被校准或学习效果已提升。

当前没有定时复习推送、LLM 自动出题或自由文本作答解析。学习记录与 Web 共用；两个入口的作答草稿不能跨端续做，飞书也看不到浏览器里尚未同步的记录。更多恢复边界见[单条复习](feishu-single-review.md)、[批次复习](feishu-batch-review.md)和[复习安排](review-arrangements.md)。
