# 章节目录与精确引用

日期：2026-10-16。属于本轮查询／阅读追踪、章节与知识变更、完整迁移及性能工作的第一批。普通大窗阅读与场景／查询核对中的阅读窗共用章节接口；私人练习卡的扩展继续暂停。

## 阅读方式

打开节点的「大窗阅读」后，完整资料旁显示当前版本的目录。点击目录可定位章节；正文中的 wiki 或本地 Markdown 笔记引用，经当前账号的知识索引解析后，可继续打开目标资料及章节。返回时回到上一份资料，主图谱选中节点、任务选择和原回答保持不变；当前实现可能重置上一份资料的滚动位置。

引用保留原目标、语法、位置和来源版本。重复标题无法确定、目标缺失、章节消失、不支持的 `^` 块引用以及不安全路径有明确提示，不假称已经定位。外部网站仍沿原安全链接规则打开，图片和附件仍沿原来源及版本校验。

阅读窗口使用冻结的资料版本，不能将它描述成始终最新。点击跨笔记引用前，会重新读取当前完整索引，核对引用源和目标的版本；不符时保留当前资料并提示重新核对。本批没有旧版正文存档、自动重定位、拆分／合并继承或完整变更账本。

## 接口与身份

`GET /api/knowledge/references?conceptId=…&sourceRevision=…` 返回当前账号完整索引中的目录及独立引用集合，遵守账号会话与 `x-lm-source-id`。版本不符返回 `SOURCE_CHANGED`，其他账号的概念不可读取。失败不妨碍阅读已经加载的正文。

章节 ID 只在该资料版本中充当逻辑定位符；HTML 实例前缀、脚注前缀不进入持久引用。目录、渲染与引用位置共用 Markdown AST 及数学正文规范化。范围的 `coordinateSpace` 为 `render-markdown-v1`，偏移和行号属于规范化后的展示正文，**不是原 Markdown 文件的绝对行号**。

Wiki 目标中的百分号保留字面意义；普通 Markdown URL 按 URL 规则解码一次。重复标题、自然后缀碰撞、同名笔记和不同语法的同一目标分别处理，不任意选第一项。

引用独立于图谱边，同一图谱关系涉及多个章节时不因边去重而丢失引用。既有概念 ID、来源版本算法、图谱边 ID 与去重规则不变。本接口只提供引用元数据，不写学习事件、不改变时间起点、H、长期保持或复习安排。

## 验证范围

合成解析、渲染、引用解析及 HTTP 检查覆盖章节定位、编码／转义、账号隔离、旧版本拒绝与学习导出保持不变；浏览器用例的实际结果以最终精确提交的 CI 为准。本地浏览器视觉与真实知识引用由本人验证。
