日期：2026-09-15。本文依据用户明确偏好，以及 progressive-kg 本地快照的结构检查。仅作 Living Memory 需求研究，未同步或改写知识库，未执行导入。

## 已明确的起点

用户倾向直接使用自建 progressive-kg 中各领域已学过、可能已会应用的概念。日常融入阅读、查询和工作，附带少量复习；视觉目标为深色、有动画的立体图谱（可先 2D），每个概念/实体用清晰颜色标注当前遗忘曲线阶段。

因此，首个场景需要利用已有知识和关系，逐步观察当前回忆与应用表现。用户曾学过是已知背景；每个概念当前能否解释、如何使用、上次何时学习，则仍需保留未知或自述来源。

## 一个贴近日常使用的候选过程

以工作中需要查询“内积”为例：

1. 从搜索进入该概念和相邻关系，直接查看需要的知识层级。
2. 根据当下意愿，选择一个简短任务，例如解释某条关系，或说明当前问题为什么需要这个概念；也可直接继续工作。
3. 记录是否查看定义、是否请求提示，以及回答或应用情境；查看后的解释与查看前的回忆分开处理。
4. 查询路径与关系展开可以产生短暂动画；当新的任务证据足以改变估计时，节点阶段色按其含义更新，并可查看理由。
5. 后续在相关阅读/工作或少量复习中再次遇到该概念，逐步获得延迟表现。

这是一份体验假设。初始接入不要求用户先完成整个知识库的测验；可通过相关任务逐步积累证据。已有内容缺少学习记录时，显示证据不足，具体中性色或其他编码尚未确定。

## 接下来需要解决的研究问题

- 对已有知识，如何以较低负担开始估计当前状态，并保留未知的历史？
- 一个概念包含多个子主题、关系和应用能力时，节点阶段色如何汇总，又如何展开差异？
- 日常查询、带资料的使用、自评和无答案提示的回忆，分别能为哪些估计提供依据？
- 阶段色如何在深色、动画与立体光照下保持清晰，且不与领域分类或临时选中状态混淆？
- 如何复用已有文件、章节链接和关系说明，避免另建需要重复维护的知识内容？
