# Living Memory v0.1 验收规格

日期：2026-09-16

状态：未来验收规格，尚未运行测试；下列指标和条件用于首次开发验收，不能视为已实现、已验证或实测结果。

范围更新：下列 AC-01～AC-23 对应完整 v0.1；当前先实施 [P0 时间驱动原型](../design/time-first-prototype.md)，按该文第 7 节的最小条件验收。P0 只让时间驱动状态，回忆观察暂不参与计算，不要求提前通过多维目标、复杂评分或语音用例。

本规格面向独立 Web 原型首版；后续宿主适配不作为本轮测试环境要求。它承接[个人记忆强化系统流程 v0.1](../design/personal-memory-workflow.md)、[日常事件触发、按需状态计算与语音通道](../design/event-triggers-and-voice.md)和[progressive-kg：首批材料与使用场景](../research/progressive-kg-context.md)。每项只规定可观察的 Given/When/Then 结果，不预设实现架构。

## 事件、投影与查询

### AC-01 事件幂等与递送溯源

- **Given**：`operation_id=O1` 合法产生不同的 `event_id`（如结果产生与结果呈现）；每个事件的原始来源、actor 和载荷已确定。
- **When**：同一 `event_id` 经另一递送通道重试，或 `O1` 下出现另一个事件；同一事件若载荷冲突也不得静默覆盖。
- **Then**：只对同事件/同语义步骤的相同载荷去重，保留原始来源/actor/载荷并另存递送通道；同 operation 的多个事件均保留，冲突返回待核对/错误。

### AC-02 事件写入失败可补写

- **Given**：查询结果已成功产生，但事件存储暂时失败。
- **When**：结果先返回，随后使用原 `event_id/operation_id` 重试写入。
- **Then**：查询结果不被阻塞或改判为记忆失败，事件以待补写状态恢复且最终只入账一次。

### AC-03 按需时间投影可重算

- **Given**：有效事件集合固定，当前时间固定为 `T`。
- **When**：在 `T` 投影一次并刷新十次，再于 `T+7天` 重新打开图谱。
- **Then**：`T` 的结果完全一致，重开时只按原证据与当前时间计算，不因刷新累积衰减、不产生新证据，也不要求每天后台扣减。

### AC-04 查询帮助不等于独立回忆

- **Given**：用户直接输入查询，未选择“先想一下”且未开始练习。
- **When**：系统返回答案、来源并完成查阅。
- **Then**：记录查询和实际呈现范围、刷新展示状态，但不创建独立回忆成功，也不延长任何复习间隔。

### AC-05 查询前回忆与查询后提示分开

- **Given**：用户选择“先想一下”，先写候选或“没有方向”。
- **When**：随后展示搜索结果、节点名或关系。
- **Then**：只有结果展示前的回答可作为自发回忆；之后暴露的内容标为提示/辅助，不回溯为原本想起。

### AC-06 缺少历史时保持未知

- **Given**：概念有 `created`、`updated` 或 `verified` 等内容日期，但没有个人学习事件。
- **When**：CLI、Voice 或图谱读取该目标状态。
- **Then**：显示“尚未评估”/unknown，不虚构人类学习日期、不判为遗忘；内容字段仍保持其原有内容语义。

## 场景、内容范围与版本

### AC-07 场景提示不算独立调用

- **Given**：场景题隐藏答案名、图谱标签、邻居和搜索结果。
- **When**：用户请求结构提示后答对，并完成反馈。
- **Then**：保存提示前后回答和提示条件，标记为辅助成功，不显示为自发调用，也不推进独立场景间隔。

### AC-08 同题或同批提示不证明迁移

- **Given**：重复同一案例，或同一批次前题刚展示了后题相关概念。
- **When**：用户在后题中答对。
- **Then**：保留该题/近期提示表现，但不新增独立迁移证据、不推进面向新情境的档位。

### AC-09 新情境按条件接受合理答案

- **Given**：新题表面和关键条件与既有案例不同，且本批次未暴露相关答案。
- **When**：用户提出合理替代概念并说明适用理由，或只漏提一次目标概念。
- **Then**：按条件与理由接受合理替代答案；一次漏提不足以判定遗忘，只有任务目标和评判依据充分时才更新对应证据。

### AC-10 L1/L2/L3 按实际呈现范围记录

- **Given**：目标内容含 L1、多个 L2 和 L3，查询过程可能读取较宽范围。
- **When**：用户实际只看到 L1，或只看到 L1 加一个指定 L2。
- **Then**：只记录实际呈现的范围；未呈现的 L2/L3、邻接节点和候选不计为已学，内容深度不直接变成记忆等级。

### AC-11 重命名或版本变化不静默沿用旧题

- **Given**：学习事件和任务引用内容版本 `v1` 的概念或章节。
- **When**：笔记被重命名、拆分或实质修改为 `v2`，随后重新载入任务和状态。
- **Then**：能有效重定位时保留映射，否则暂停失效题目；历史表现仍归 `v1`，`v2` 待重新确认，不得静默套用旧结果，重算过程可追溯。

### AC-12 跳过与争议反馈保持中性

- **Given**：用户跳过、退出、没时间、回答来源未知，或反馈因来源不足/过时而有争议。
- **When**：尝试结束或反馈被更正。
- **Then**：记录 skipped/unknown 或待核对及更正原因，不当失败、不降低能力状态、不推进间隔；争议未解决前不改掌握判断。

## 通道、图谱与语音

### AC-13 真实 Voice 与 CLI 使用同一知识结果

- **Given**：使用真实 ChatGPT Voice 客户端访问真实 progressive-kg 文件/章节，并准备一份可安全修改的测试材料 `v1→v2`；CLI 仅作对照，不能模拟 Voice 验收。
- **When**：Voice 在修改前后查询该材料，同时在同一受控时间读取 CLI 的引用/状态；若无实际播报遥测，将呈现状态记为 unknown。
- **Then**：Voice 返回可追溯的真实文件、章节和新版本内容，并与 CLI 共享引用/投影语义；不得把 CLI 模拟、unknown 呈现或模型总结当作听完或独立学习证据。

### AC-14 Voice 中断不虚构呈现或遗忘

- **Given**：语音停顿、转写延迟/错误、网络失败或播报被中断。
- **When**：交互事件被记录或稍后修正。
- **Then**：只保存已观察的转写、原始表达、提示范围和实际播报范围及中断状态；无可靠呈现遥测时记为 unknown，不推断完整呈现、回忆成功或遗忘。

### AC-15 导入保持稳定身份、关系、中文与未解析引用

- **Given**：导入材料含概念文件/章节、别名、关系边、中文标题，以及一个无法解析的引用。
- **When**：材料被导入、重载或再次查询/绘图。
- **Then**：在可证明的稳定映射下概念身份、章节定位和关系端点保持不变，中文标签保留；重命名/拆分/合并歧义不猜测继承，未解析引用显式标记并保留来源位置。

### AC-16 真实 3D 交互与状态图例稳定

- **Given**：真实 3D 图谱包含 unknown、到再确认窗口等状态，并有对应文字/颜色图例。
- **When**：用户旋转、平移、缩放、选中节点，且节点状态发生变化。
- **Then**：交互持续可用，图例明确区分 unknown 与到期/待确认；状态变化只更新相应颜色/标签，不重排节点或改变稳定空间布局。

## 性能、恢复与工作边界

### AC-17 Web 首版性能与资源生命周期

- **Given**：先记录目标浏览器及版本、OS 及版本、CPU/GPU、屏幕/视口和 DPR；用合成 300 节点/1000 边、1920×1080、内部 DPR≤1.5 的 Web 图谱，所有指标均为初拟目标而非实测结论。
- **When**：预热后中档连续镜头操作 30 秒并测中位/最低 FPS，验证最低档可操作；再预热后开关视图 10 次并记录活动视图、订阅、RAF、内存和 `renderer.info` 趋势。
- **Then**：中档中位 FPS≥30、最低档仍可操作；开关后活动视图/订阅/RAF 回到基线，隐藏视图停止渲染且可恢复，内存/`renderer.info` 以趋势判断而非仅凭 GC 波动判失败。

### AC-18 重启、迁移、备份与导入保持状态

- **Given**：备份/导出包含学习事件、内容版本、稳定身份映射、关系、配置和规格版本。
- **When**：应用重启，或在干净实例中迁移并再导入该备份。
- **Then**：状态、证据、引用、身份映射、关系和配置恢复一致；版本信息可追溯，不静默丢失、重复或重新指派目标。

### AC-19 任务预算可为零且无债务

- **Given**：每日主动任务预算设为 0，或目标被暂停；同时存在到期任务。
- **When**：进入应用、跨过到期日期或用户跳过任务。
- **Then**：不强制提供任务；暂停/跳过不算失败、不降低状态、不累积必须偿还的复习债务，历史和待确认状态保留并按以后预算重排。

### AC-20 真实工作应用与总结可保存但不冒充回忆

- **Given**：用户在真实工作中借助查询、资料或他人/AI 帮助应用概念，并可附来源写总结。
- **When**：保存场景、概念、条件、结果、限制或总结。
- **Then**：保留应用经历和来源/总结，分类为使用或辅助证据；不自动生成独立回忆成功、场景自发调用证据或复习推进。

### AC-21 本地错误、凭证与语音数据边界

- **Given**：本地配置错误、服务不可用或凭证缺失，且源码检查不得包含私有 progressive-kg；Voice 默认不启用音频保存。
- **When**：启动/操作失败，或用户主动保存一次口述尝试。
- **Then**：显示可行动错误且不伪造学习事件；默认不保存音频，仅在主动保存时保留完成该尝试所需的必要转写片段，并提供清除路径。

## 记忆目标与训练闭环

### AC-22 记忆目标独立且依据可检查

- **Given**：同一概念分别建立核心解释、关键细节、场景提取和适用判断目标，并记录提示依赖、近期接触、独立回忆、延迟与结果。
- **When**：用户完成其中一个目标，或系统按当前时间展示记忆/遗忘状态。
- **Then**：只更新对应目标和内容版本；依据可逐项查看，近期接触不冒充独立回忆，会解释核心内容不延后场景任务，也不点亮全部细节。

### AC-23 反馈驱动巩固与保守调度

- **Given**：用户可在回答前预测把握程度但可以跳过，随后提交回答并接受或修正反馈。
- **When**：反馈区分遗漏、误解、提示依赖或前提误用，且存在即时重做或近期曝光。
- **Then**：分别触发补关键细节、对比概念或更换场景等巩固动作，再安排延迟检验；即时重做/近期曝光不升级间隔，规则透明且不显示未经校准的假概率。

## 少量 fixture 与测试类型

建议只准备以下最小 fixture，不扩大产品范围：

- 一份非敏感中文概念材料：含 L1、两个 L2、关系、真实文件/章节引用、未解析引用，并可产生 `v1→v2` 修改。
- 一组事件/任务样本：无历史、直接查询、查询前回忆、结构提示、同题/新题、跳过、争议反馈、重复 `event_id/operation_id` 和待补写事件；覆盖核心解释、关键细节、场景提取、适用判断四类独立目标，以及遗漏/误解/提示依赖/前提误用反馈。
- 一组真实通道样本：真实 ChatGPT Voice 客户端与真实资源文件章节引用；分别覆盖有/无播报遥测，禁止用 CLI 模拟 Voice 验收。
- 一组图谱与设备样本：300 节点/1000 边性能图、目标浏览器/OS/硬件/屏幕/DPR 元数据、备份导出包及干净实例。
- 一组故障样本：错误配置、离线服务、缺失凭证、重启/迁移和用户主动清除转写。

测试类型仅按需要采用：确定性单元/投影测试、事件与文件导入集成测试、真实 CLI/Voice 端到端与人工核对、真实 3D 交互测试、性能/资源趋势测试、重启迁移恢复测试和本地数据边界检查。本文件截至日期尚未运行这些测试。
