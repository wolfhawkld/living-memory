# 可视化体验与视觉编码 v0.1

日期：2026-09-15。用户认可个人记忆强化流程的大方向，本轮进入可视化分析与选型。本文提出可评审的视觉与交互方案，技术比较见[渲染与布局选型](../research/visualization-options.md)，可操作的风格示意见[离线视觉预览](../../prototypes/visual-direction.html)。

已确认的方向是深色背景、动画、立体图谱（允许先 2D）、节点颜色表达记忆/遗忘相关状态。用户查看官方 `3d-force-graph` 示例后进一步确认桌面 3D 原型采用 **`3d-force-graph` + Three.js**，并选择**突出空间纵深、较明显的发光、镜头聚焦与关系高亮**。以下据此以该路线作为原型主线；具体组件版本、标签与交互实现、配色和动画参数仍是可调整建议，当前尚未完成引擎、性能或宿主集成测试。

## 1. 本轮建议

采用**深色空间星图、明显但可控的发光、围绕任务的镜头运动**。3D 为主要探索与定位视图，并提供平面阅读模式和固定详情面板；坐标在布局稳定后保存，光效与镜头运动不要求节点持续漂移。

空间感可以由层次、背景与光效表达，但 CSS 倾斜或节点阴影只是视觉纵深，不等于真正的三维坐标、透视和遮挡。二维视图使用 WebGL 也不会因此成为三维图谱。

| 表达方案 | 主要价值 | 需要承担的成本 | 本轮定位 |
| --- | --- | --- | --- |
| 平面阅读模式 | 对照标签、阅读关系、快速定位；易与笔记并排 | 需明确镜头与手势；WebGL 平面模式不等于独立 Canvas 2D | 同一工作区的阅读入口 |
| 平面加视觉纵深 | 快速比较光晕、层次和空间气质 | 不能代表真实三维遮挡、旋转与性能 | 本轮离线风格示意 |
| 真正 3D 空间图谱 | 通过镜头聚焦、旋转、空间层次探索关系 | 遮挡、镜头定位、标签、拾取、显卡负担都需验证 | 优先引擎原型主线 |

这是产品判断，未证明某种视图能提升记忆；学习收益仍需按[流程验证计划](../research/validation-plan.md)观察。

## 2. 页面组织与主要交互

工作区由搜索/主题入口、中心图谱、按需展开的概念详情组成。底部或角落固定显示当前观察目标、状态图例和布局操作；先找到知识，再按需要展开证据和任务。

| 操作 | 视觉回应 |
| --- | --- |
| 输入搜索 | 匹配名称和别名，提供文字结果；选择后定位节点并显示完整标签 |
| 选中概念 | 保留原布局，突出该节点及一阶关系，旁侧显示解释、来源和个人状态 |
| 展开相邻关系 | 用户主动扩大范围，说明当前有哪些关系被显示；支持返回上一次焦点 |
| 查看一条关系 | 显示关系类型、方向和解释；有来源则可追溯，推测关系明确标记 |
| 切换主题或状态目标 | 改变过滤和编码，不因为颜色改变而重新计算节点位置 |
| 发起回忆 | 根据任务规则显示允许的线索；场景调用练习切到独立面板，收起泄漏候选的图谱 |
| 完成任务 | 显示本次观察，再更新受影响目标的状态；可查看改变原因 |
| 回到总览 | 明确按钮恢复保存的总览位置，不依赖连续缩放寻找原位置 |

图谱之外保留文字列表与键盘入口；全部关键操作不依赖悬浮鼠标。窄屏将详情变成下方或独立面板，优先保持搜索、选择和正文阅读。

## 3. 每一种视觉属性只承担明确的含义

| 视觉属性 | 建议含义 | 具体约束 |
| --- | --- | --- |
| 节点填色/状态标记 | 当前所选目标的记忆证据与再访阶段 | 图例常驻，不用同一填色同时区分学科 |
| 空心状态与文字 | 尚未评估/证据不足 | 不是已忘记；真实冷启动允许大量节点处于这个状态 |
| 额外外环 | 选中、键盘焦点 | 保留节点原状态色 |
| 节点大小 | 初版保持同类节点基本一致，聚合节点另标数量 | 不暗示知识价值、记忆强度或智力 |
| 空间分组与区域标题 | 学科/主题导航及局部关系 | 距离由布局产生，不宣称是认知距离或相似度的测量 |
| 连线、箭头、关系文字 | 实际记录的关系及方向 | 无向相关关系不用箭头；知识网络整体允许环 |
| 连线虚实 | 在展示需要时区别有依据关系与待核对推测 | 配文字解释；不将未核对建议自动写回知识库 |
| 短暂路径动画 | 本次查询、定位或关系展开 | 不表示记忆沿连线自动传播 |

整体网络不因包含前置关系就强行采用 DAG 布局；只有用户明确查看无环依赖子图时，才考虑层级布局。布局与知识结构分开存储，调整坐标不修改语义关系。

## 4. 状态颜色与图例

保留[系统流程](personal-memory-workflow.md)对状态的区分。初期采用观察和透明再访规则，没有经过校准的个人遗忘概率；因此图例明确写出“依据表现与再访安排”。

| 内容保持视图中的状态 | 候选色 | 额外表达 |
| --- | --- | --- |
| 尚未评估 | 灰蓝 `#91A0B7` | 空心节点、未评估文字 |
| 近期有独立回忆证据 | 青绿 `#66D5B5` | 状态文字及最近观察日期 |
| 到再确认窗口 | 琥珀 `#E9BC68` | 待确认标签及安排依据 |
| 最近表现需要巩固 | 柔和珊瑚 `#E98A92` | 提示、遗漏或错误的具体说明 |

这些色段是产品表达，不是普遍生物阶段。模型验证后若引入预测曲线，需要单独标出预测对象、时间、不确定性和模型依据；不能把当前颜色直接换算成知识剩余百分比。

总览默认观察“核心解释”；细节需要选择具体目标。切换到“场景调用”时显示独立调用、辅助获得或尚无证据等相应图例，不沿用内容保持的再访阶段来冒充迁移概率。某维度缺少记录时，另一维度的成功不能替它填色。

查询与阅读仅产生操作反馈，不直接把状态改成近期独立回忆成功。模拟任务造成的颜色变化始终注明为演示，不进入个人学习历史。

## 5. 文字、关系与信息密度

总览突出主题与少量必要标签；局部视图优先显示选中节点及直接邻居；放大或选中后显示完整名称、关系类型和详细解释。长期目标是可控的信息层级，而不是在一个缩放比例上铺开所有文字。

- 中文标签以屏幕可读大小绘制，避免随着三维远近不断缩成难辨的点；详情面板使用普通网页文字处理长名称、公式和来源。
- 标签避让与节点碰撞分开处理：圆点不重叠不能证明长文字不重叠。需要测量实际字形边界、优先级和缩放后的占位。
- 不用省略号隐藏唯一辨识信息；选中、搜索和文字列表始终提供完整名称。
- 关联线多时先突出当前焦点的关系，不把所有连线和关系标签同时设为高亮。
- 三维标签可朝向相机，但关键标签应有遮挡处理；详细段落放在固定阅读面板，避免在空间里漂浮大段文字。

具体字号、同时显示数量和避让策略用中文样例测试后定，不先承诺固定标签上限或性能容量。

## 6. 布局稳定与动画

首次进入可以运行布局，稳定后停止持续模拟并保存坐标。重新进入恢复原位置；状态或颜色更新不触发布局。添加节点时优先放到相关区域，再局部调整，旧节点可作为固定锚点；允许用户拖动固定与主动重新布局。

这是一项交互目标，不由“力导向”三个字自动保证。D3 的模拟提供停止、继续、手动迭代和固定 `fx/fy` 的能力，应用仍需处理持久化、增量变化和标签布局。[D3 force simulation](https://d3js.org/d3-force/simulation)

动画初始建议：定位移动约 250–450 ms；选择或状态过渡约 150–300 ms；查询路径只播放一次约 600–900 ms。以上为风格试验参数，不是认知实验确定的最佳值。

根据本轮偏好，跨主题聚焦可尝试约 500–900 ms 的镜头过渡，包含距离变化和有限角度调整；局部选中使用更短过渡。拖动或再次选择可中断当前镜头动画。发光可强调节点轮廓与当前路径，标签和可读状态标记使用清晰独立层，避免随泛光一起变白。提供光效强度调节，阅读模式降低光效并固定视角。

默认不持续旋转相机、不让节点永久漂浮、不让全部连线持续流动。用户可主动进入探索并旋转 3D 镜头；停止操作后保留视角。减少动态效果时取消非必要位移与闪动，保留即时的文字和选择反馈。

## 7. 候选基础色与可读性

背景 `#080D19`，面板 `#111A2B`，正文 `#E8EDF8`，次级文字 `#AAB7CE`，重要边界 `#586A86`。青绿、琥珀和珊瑚用于状态；白色外环用于选择，光晕只作为辅助。

本轮用 sRGB 相对亮度公式计算的不透明色对比度如下：

| 颜色用途 | 对背景 | 对面板 |
| --- | ---: | ---: |
| 正文 | 16.54:1 | 14.84:1 |
| 次级文字 | 9.59:1 | 8.60:1 |
| 未评估状态色 | 7.32:1 | 6.56:1 |
| 近期独立回忆色 | 10.86:1 | 9.74:1 |
| 待再确认色 | 10.96:1 | 9.83:1 |
| 需巩固色 | 7.87:1 | 7.06:1 |
| 重要边界 | 3.53:1 | 3.17:1 |

这是颜色令牌检查，不等于整张界面通过可访问性评估；透明度、渐变、光晕、细线、抗锯齿及三维光照都会影响实际显示。需要辨认的关系、控制和状态在最终合成背景上另行检查。

参考 WCAG 2.2：普通文字通常要求至少 4.5:1；承载必要信息的非文字视觉元素适用 3:1 的相关要求；颜色还需要文字或其他标记共同表达。提供减少非必要交互动画的方式。[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)、[颜色使用](https://www.w3.org/WAI/WCAG21/Understanding/use-of-color)、[交互动画](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)

## 8. 如何评审这次预览与下一轮引擎原型

离线预览仅用于讨论中文、配色、信息密度、选择反馈和光效。其示例节点、关系、状态和固定坐标都不来自用户的真实学习记录，也不提供遗忘曲线或真实三维引擎性能证据。

依次检查：是否喜欢总体气质；能否从图例理解状态；能否定位一个中文概念并读清邻居；选择时状态颜色是否保持；动画是否帮助追踪；关闭动画和用键盘是否仍可完成操作。

真正的图谱引擎原型再检查动态布局、导入、增量更新、大图帧率、三维遮挡、缩放标签和宿主适配。不要用小型静态预览的顺滑推断大型图谱性能，也不以审美认可代替记忆训练效果验证。
