# 关键细节与概念辨别：批量开发目标

日期：2026-10-02。用户要求继续按整体 goal 推进后续 TODO，并允许几个大功能就绪后集中测试。本批承接 LM-010/LM-011/LM-012 的人工目标与辨别任务子集。

## 本批范围

1. 私人练习卡管理：选定值得保持的关键细节；编写概念比较、适用条件或反例问题。人工填写题干、参考答案和出处，核对当前资料后保存。修订追加版本，支持暂停和恢复。
2. 自愿练习：可选事前信心，先回答再显示核对依据，保存自评、查阅条件和核对笔记。练习期间隐藏旧答案和参考资料，原回答和请求 ID 固定，失败可以重试。
3. 历史与再访：按卡区分各个问题版本和资料版本，列出当前版本的最近自评及历史回答。资料变化先复核；不把旧题成绩迁到新题。账号隔离、JSON 导出预览恢复与幂等重试一起完成。

这些练习使用独立记录，不进入整个概念解释或场景调用的成绩、信心汇总及时间表现对照。保存、修订、暂停、作答均不更新重温起点、不解除手动长期保持、不拟合 H，也不改写 progressive-kg。

## 完成边界

合成资料和隔离数据库上的自动检查、构建、文档、develop 提交推送完成后，更新保留个人数据的本地服务，提供一份合并人工验收清单。浏览器视觉、题目与参考答案的正确性、真实延迟记忆收益由本人稍后验收；软件检查不代表记忆收益已经验证。

原 LM-010/011 的完整多维目标与规则调度、场景案例族及分阶段提示、反馈争议的修订事件仍有后续范围。ChatGPT 原生语音、共享融合和 Obsidian 继续遵循各自的前置条件，不纳入本批。
