# 场景卡与分阶段提示：批量开发目标

日期：2026-10-02。用户要求开启下一项 goal，沿用多个功能就绪后集中验收的安排。本批承接 LM-011 的人工场景、案例族与分阶段提示范围。

## 本批范围

1. 在私人练习卡中增加人工场景卡：手工题干、核对答案、出处、1～4 个当前来源、案例族标签，以及可选结构提示和名称提示。每次修改追加版本，来源改变后重新核对。
2. 保留最初无提示原答，再按需查看结构或名称提示。显示下一阶段提示前冻结上一阶段回答；核对时逐阶段分别自评候选概念召回与适用理由，允许合理替代答案。
3. 历史保留各阶段原答、时间和提示条件。记录题目或同案例族的既往接触，不将同题重练或名称提示后的作答解释成新场景迁移。完成账号隔离、固定请求重试、旧库升级与 JSON 预览恢复。

新记录仍保存在独立练习表，不进入旧概念解释 / 场景观察成绩、信心汇总、复习预算或时间对照；不改 H、重温起点、长期保持，也不自动修改 progressive-kg。

## 完成边界

自动检查只使用合成资料和隔离存储。构建、文档、develop 提交推送与 CI 完成后，备份并更新原个人服务。没有本地浏览器验证；题目、提示与核对依据的准确性、图形体验和真实记忆收益由本人与前两批功能集中验收。
