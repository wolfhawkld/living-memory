## 第一项的可开发范围

- [ ] 提供按当前知识源和概念查询历史的只读接口，明确时间排序及数量边界，不要求前端下载整份导出文件。
- [ ] 节点详情展示确认重温、估计重温、回忆观察；保留发生时间与记录时间的区别，以及来源版本。
- [ ] 展开回忆观察时查看原回答、自评、资料曝光、当时的时间指标及模型参数版本，不用今天的曲线重算并覆盖历史值。
- [ ] 标明哪个有效事件是当前时间起点；保留不再适用于当前来源版本的历史，给出明确说明。
- [ ] 区分真实记录、示例状态、浏览器待同步记录；空历史与加载失败有对应提示。回忆任务作答期间继续遮蔽历史答案。
- [ ] 验证跨来源/跨概念隔离、补记排序、重复事件、版本变化，以及读取历史不会新增事件或改变曲线。

这些是下一项的范围与验收草案，尚未实现；不同时加入自动评分、个人遗忘率拟合或整套任务调度。
